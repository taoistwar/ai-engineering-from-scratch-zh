# 宪制AI与规则覆盖

> Anthropic于2026年1月22日发布的Claude Constitution长达79页，采用CC0许可。它从基于规则的对齐转向基于推理的对齐，并建立了四层优先级层次结构：(1)安全性和支持人工监督，(2)伦理，(3)Anthropic指南，(4)有用性。行为分为操作者和用户不能覆盖的硬编码禁止（生物武器提升、CSAM）以及操作者可以在定义范围内调整的软编码默认值。2022年的原始版本（Bai等人）通过自我批评和针对一部宪法的RLAIF训练无害性。诚实的警示：基于推理的对齐依赖模型将原则推广到未预见的情况。Anthropic在2023年的参与式实验显示公众来源与公司原则之间约有50%的分歧；2026年版本未纳入这些发现。

**Type:** Learn
**Languages:** Python (stdlib, four-tier priority resolver)
**Prerequisites:** Phase 15 · 06 (Automated alignment research), Phase 15 · 10 (Permission modes)
**Time:** ~60 minutes

## 问题

一个实地部署的智能体会遇到其设计者从未见过的输入。没有规则列表长到足以覆盖这些输入。没有规则列表短到足以在计算压力下快速应用。实际问题是：你如何将智能体与能在长尾案例和快速推理中都能存活的原则对齐？

基于规则的对齐（RBA）：列出每一种不允许的事情。检查快，容易审计，不可能保持最新，常常对它未预料到的相似情况过度拒绝。基于推理的对齐（2026年Claude Constitution）：编码原则，让模型推理。可扩展到未见案例，更难审计，失败模式是原则误用而非遗漏规则。

2026年Constitution采取了明确的中间立场。硬编码禁止——其错误性不依赖于上下文的事情（生物武器提升、CSAM）——是RBA：绝不，无论操作者或用户指令如何。其他一切在四层层次结构内基于推理：安全性和支持人工监督优先；伦理其次；Anthropic声明的指南第三；有用性最后。操作者可以在软编码区域调整默认值，但不能触碰硬编码禁止。

## 概念

### 四层优先级层次结构

1. **安全性和支持人工监督。** 最高。模型优先考虑不削弱人类和Anthropic监督和纠正AI的能力。这不是"保持谨慎"；它具体是"不以使人工监督更困难的方式行动。"
2. **伦理。** 诚实，避免对人造成伤害，不欺骗，不操纵。当与Anthropic指南冲突时优先生效。
3. **Anthropic指南。** Anthropic认为重要的操作规范：产品范围、交互模式、何时使用什么工具。
4. **有用性。** 最低。在更高优先级范围内尽可能有用。

当层级冲突时，更高的获胜。这与Unix优先级或网络QoS形状相同——框架旨在产生可预测的解决方案，不一定是任何单一轴上的最佳行为。

### 硬编码禁止 vs 软编码默认值

**硬编码：**
- 生物武器 / CBRN提升
- CSAM
- 对关键基础设施的攻击
- 被直接询问时对用户欺骗模型的身份

操作者不能覆盖这些。用户不能覆盖这些。它们在可能的地方（RLHF / Constitutional AI训练）在模型权重级别执行，在不可能的地方在推理层执行。

**软编码默认值（操作者可调整）：**
- 回复长度默认值
- 主题范围（模型可以拒绝操作者部署范围外的话题）
- 风格（正式 vs 随意）
- 工具使用模式

操作者的调整在声明的边界内发生。操作者不能通过重命名来移除硬编码禁止。

### 2022年CAI训练

原始的Constitutional AI（Bai等人，2022年）训练无害性：

1. 为一组提示生成回复。
2. 让模型根据一部宪章（显式原则）批评每个回复。
3. 基于批评修订回复。
4. 在修订后对上进行RLAIF（从AI反馈中强化学习）。

结果：一个以原则性解释拒绝有害请求的模型，而非一刀切拒绝。2026年Constitution使用此训练的后裔，加上对显式层级层次结构的额外后期训练。

### 基于推理的对齐捕获了什么、遗漏了什么

**捕获：**
- 原则明确适用的允许原语的未预见组合。
- 是禁止项相似物的新颖请求。
- 依赖"你没有说X被禁止"的社会工程攻击。

**遗漏：**
- 利用原则模糊性的攻击（"用户要求了这个，所以有用性说是"）。
- 两个原则以未预见方式冲突且层级顺序模糊的场景。
- 训练周期中原则解释的缓慢漂移（重新解释）。

### 2023年参与式实验

Anthropic在2023年进行了一项实验，比较了公司撰写的宪章与通过公众输入生成的宪章（约1000名美国受访者）。两个版本在大约50%的原则上达成一致。它们分歧的地方，公众来源版本在某些问题上更具限制性（政治内容处理），在其他问题上限制较少（AI身份的自我披露）。2026年Constitution未纳入公众来源的发现。这是该方法中一个有记录的张力。

### 为什么硬编码禁止是必要的

仅有基于推理的对齐无法闭合尾部。一个能让模型接受前提的攻击者（例如"我们是获得许可的生物武器研究实验室"）常常能绕过依赖案例推理的原则。硬编码禁止不向前提框架弯曲。它们是在对齐层的第14课"硬宪制限制"。

### Constitution在技术栈中的位置

Constitution不是第14课的熔断开关。它存在于模型层：模型权重被训练偏好什么。熔断开关和金丝雀令牌存在于运行时层：运行时允许什么。两者都需要。因模型权重宽松而触发所有错误行动的运行时是运行时问题。因运行时过度限制而拒绝所有正确行动的模型是运行时问题。层覆盖不同类别。

## 运用

`code/main.py` 实现一个极简的四层优先级解析器。解析器接受提议的行动和一组原则评估（安全性、伦理、指南、有用性），返回行动、拒绝或修改后的行动。驱动程序运行一个小案例集：明确允许、明确禁止、硬编码禁止、跨层模糊案例。

## 交付物

`outputs/skill-constitution-review.md` 审计部署的宪制层：什么被硬编码，什么是软编码，操作者在哪里可以调整，四层层次结构是否确实是解析顺序。

## 练习

1. 运行 `code/main.py`。确认即使有用性高，硬编码禁止也会触发。修改解析器使有用性权重高于伦理；观察失败模式。

2. 阅读Claude Constitution（公开，79页，CC0）。确定一个你认为规定不足的原则。写两段话解释具体的模糊性，并提议更严格的表述。

3. 为客户支持智能体设计软编码默认值集合。操作者调整什么？操作者不能触碰什么？证明每个边界。

4. 阅读Bai等人2022年CAI论文。描述一个Constitutional AI的批评并修订循环会产生比一刀切规则更差结果的情况。识别类别。

5. Anthropic 2023年参与式实验发现公众与公司原则之间约有50%的分歧。选择一个在生产部署中重要的类别（例如政治中立性）。提出一个让操作者表达自己价值观而硬编码禁止保持不变的设���。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|---|---|---|
| Constitutional AI | "Anthropic的对齐方法" | 针对一部书面宪章的自我批评 + RLAIF |
| 基于推理的对齐 | "原则，而非规则" | 模型通过原则推理来处理未见案例 |
| 硬编码禁止 | "绝不X" | 操作者或用户无法覆盖的基于规则的禁止 |
| 软编码默认值 | "操作者可调整" | 在声明边界内的行为，操作者控制 |
| 四层层次结构 | "优先级顺序" | 安全性 > 伦理 > 指南 > 有用性 |
| RLAIF | "AI反馈RL" | 奖励来自模型生成批评的RL |
| 参与式宪章 | "公众来源的原则" | 2023年Anthropic实验；与公司版本约50%分歧 |
| 原则漂移 | "解释滑动" | 模型阅读固定原则文本方式的缓慢变化 |

# 范数与距离

> 你的距离函数定义了"相似"的含义。选错了，下游一切都会崩溃。

**类型：** 构建
**语言：** Python
**先决条件：** 阶段 1，第 01 课（线性代数直觉），第 02 课（向量、矩阵与运算）
**时间：** ~90 分钟

## 学习目标

- 从头实现 L1、L2、余弦、马氏、Jaccard 和编辑距离函数
- 为给定的 ML 任务选择合适的距离度量，并解释为什么替代方案会失效
- 将 L1 和 L2 范数与 LASSO 和 Ridge 正则化及其几何约束区域连接起来
- 演示同一数据集在不同度量下产生不同的最近邻

## 问题

你有两个向量。可能是词嵌入。可能是用户画像。可能是像素数组。你需要知道：它们有多近？

答案完全取决于你选择哪种距离函数。两个数据点在一种度量下可能是最近邻，在另一种度量下则相距甚远。你的 KNN 分类器、推荐引擎、向量数据库、聚类算法、损失函数——它们都取决于这个选择。选错了，你的模型就会优化错误的目标。

不存在万能的"最佳"距离。L2 适用于空间数据。余弦相似度在 NLP 中占主导地位。Jaccard 处理集合。编辑距离处理字符串。马氏距离考虑相关性。Wasserstein 距离移动概率质量。每一种都编码了关于"相似"含义的不同假设。

本课从头构建每一个主要的距离函数，向你展示何时每种是合适的工具，并演示相同数据在不同度量下如何产生完全不同的最近邻。

## 概念

### 范数：测量向量的大小

范数测量向量的"大小"。两个向量之间的每个距离函数都可以写成它们差的范数：d(a, b) = ||a - b||。因此理解范数就是理解距离。

### L1 范数（曼哈顿距离）

L1 范数对每个分量的绝对值求和。

```
||x||_1 = |x_1| + |x_2| + ... + |x_n|
```

它被称为曼哈顿距离，因为它测量的是你在城市网格中走路需要的距离，在那里你只能沿坐标轴移动。不能走对角线。

```
点 A = (1, 1)
点 B = (4, 5)

L1 距离 = |4-1| + |5-1| = 3 + 4 = 7

在网格上，你向东走 3 个街区，向北走 4 个街区。
```

何时使用 L1：
- 高维稀疏数据（文本特征、独热编码）
- 当你希望对异常值具有鲁棒性时（单一的巨大差异不会主导结果）
- 特征选择问题（L1 正则化促进稀疏性）

与 L1 正则化（Lasso）的联系：将 ||w||_1 添加到损失函数中会惩罚权重绝对值的和。这会将小权重推到恰好为零，执行自动特征选择。L1 惩罚在权重空间中创建菱形约束区域，菱形的角位于某些权重为零的坐标轴上。

与损失函数的联系：平均绝对误差（MAE）是预测和目标之间 L1 距离的平均值。它线性地惩罚所有误差，与 MSE 相比对异常值具有鲁棒性。

### L2 范数（欧几里得距离）

L2 范数是直线距离。各分量平方和的平方根。

```
||x||_2 = sqrt(x_1^2 + x_2^2 + ... + x_n^2)
```

这是你在几何课上学过的距离。n 维中的勾股定理。

```
点 A = (1, 1)
点 B = (4, 5)

L2 距离 = sqrt((4-1)^2 + (5-1)^2) = sqrt(9 + 16) = sqrt(25) = 5.0

直线，沿对角线穿过网格。
```

何时使用 L2：
- 低到中等维度的连续数据
- 当特征的尺度可比时
- 物理距离（空间数据、传感器读数）
- 像素级别的图像相似度

与 L2 正则化（Ridge）的联系：将 ||w||_2^2 添加到损失函数中会惩罚大权重。与 L1 不同，它不会将权重推到零。它按比例将所有权重收缩到零。L2 惩罚创建圆形约束区域，因此没有轴上的角。权重变小但很少恰好为零。

与损失函数的联系：均方误差（MSE）是 L2 距离平方的平均值。平方对大误差的惩罚比小误差更重。

```
MAE（L1 损失）：  |y - y_hat|         线性惩罚。对异常值鲁棒。
MSE（L2 损失）：  (y - y_hat)^2       二次惩罚。对异常值敏感。
```

### Lp 范数：一般族系

L1 和 L2 是 Lp 范数的特例：

```
||x||_p = (|x_1|^p + |x_2|^p + ... + |x_n|^p)^(1/p)
```

不同的 p 值产生不同形状的"单位球"（距离原点为 1 的所有点的集合）：

```
p=1:    菱形              （角在坐标轴上）
p=2:    圆/球             （通常的圆球）
p=3:    超椭圆            （圆角正方形）
p=inf:  方形/超立方体     （各面沿坐标轴）
```

### L-无穷范数（切比雪夫距离）

随着 p 趋近无穷，Lp 范数收敛到最大绝对值分量。

```
||x||_inf = max(|x_1|, |x_2|, ..., |x_n|)
```

两点之间的距离由它们差异最大的单一维度决定。所有其他维度被忽略。

```
点 A = (1, 1)
点 B = (4, 5)

L-inf 距离 = max(|4-1|, |5-1|) = max(3, 4) = 4
```

何时使用 L-无穷：
- 当任何单一维度中的最坏情况偏差很重要时
- 棋盘（国际象棋中的国王按 L-无穷移动：向任意方向走一步都花费 1）
- 制造公差（每个维度必须在规格范围内）

### 余弦相似度和余弦距离

余弦相似度测量两个向量之间的角度，忽略其大小。

```
cos_sim(a, b) = (a . b) / (||a||_2 * ||b||_2)
```

它的范围从 -1（相反方向）到 +1（相同方向）。垂直向量的余弦相似度为 0。

余弦距离将其转换为距离：余弦距离 = 1 - 余弦相似度。范围从 0（相同方向）到 2（相反方向）。

```
a = (1, 0)    b = (1, 1)

cos_sim = (1*1 + 0*1) / (1 * sqrt(2)) = 1/sqrt(2) = 0.707
cos_dist = 1 - 0.707 = 0.293
```

为什么余弦在 NLP 和嵌入中占主导地位：在文本中，文档长度不应影响相似度。一篇关于猫的文档，如果长度是另一篇的两倍，仍应"相似"。余弦相似度忽略大小（长度），只关心方向。两篇词分布相同但长度不同的文档指向相同方向，余弦相似度为 1.0。

何时使用余弦相似度：
- 文本相似度（TF-IDF 向量、词嵌入、句子嵌入）
- 任何大小是噪声而方向是信号的领域
- 推荐系统（用户偏好向量）
- 嵌入搜索（向量数据库几乎总是使用余弦或点积）

### 点积相似度 vs 余弦相似度

两个向量的点积是：

```
a . b = a_1*b_1 + a_2*b_2 + ... + a_n*b_n
      = ||a|| * ||b|| * cos(角度)
```

余弦相似度是用两个大小归一化的点积。当两个向量都已经是单位归一化（大小为 1）时，点积和余弦相似度是相同的。

```
如果 ||a|| = 1 且 ||b|| = 1：
    a . b = cos(a 和 b 之间的角度)
```

当它们不同时：点积包含大小信息。具有较大大小的向量获得更高的点积分数。这在某些检索系统中很重要，你希望"热门"项目排名更高。大小充当隐式的质量或重要性信号。

```
a = (3, 0)    b = (1, 0)    c = (0, 1)

dot(a, b) = 3     dot(a, c) = 0
cos(a, b) = 1.0   cos(a, c) = 0.0

两者在方向上一致，但点积也反映大小。
```

在实践中：
- 当你想要纯粹的方向相似度时使用余弦相似度
- 当大小携带有意义的信息时使用点积
- 许多向量数据库（Pinecone、Weaviate、Qdrant）让你在它们之间选择
- 如果你的嵌入是 L2 归一化的，选择哪个不重要

### 马氏距离

欧几里得距离平等对待所有维度。但如果你的特征是相关的或具有不同的尺度，L2 会给出误导结果。

马氏距离考虑了数据的协方差结构。

```
d_M(x, y) = sqrt((x - y)^T * S^(-1) * (x - y))
```

其中 S 是数据的协方差矩阵。

直观上：马氏距离首先去相关和归一化数据（白化），然后在那个变换空间中计算 L2 距离。如果 S 是单位矩阵（不相关、单位方差的特征），马氏距离退化为欧几里得距离。

```
例如：身高和体重是相关的。
某人 6'2" 高 180 磅并不罕见。
某人 5'0" 高 180 磅是异常的。

欧几里得距离可能说它们离均值同样远。
马氏距离正确地将第二个识别为异常值，
因为它考虑了身高-体重相关性。
```

何时使用马氏距离：
- 异常检测（从均值计算的大马氏距离点是异常值）
- 当特征具有不同的尺度和相关性时的分类
- 当你有足够数据估计可靠协方差矩阵时
- 制造业中的质量控制（多元过程监控）

### Jaccard 相似度（用于集合）

Jaccard 相似度测量两个集合之间的重叠。

```
J(A, B) = |A 交 B| / |A 并 B|
```

范围从 0（无重叠）到 1（相同集合）。Jaccard 距离 = 1 - Jaccard 相似度。

```
A = {猫, 狗, 鱼}
B = {猫, 鸟, 鱼, 蛇}

交集 = {猫, 鱼}         大小 = 2
并集 = {猫, 狗, 鱼, 鸟, 蛇}  大小 = 5

Jaccard 相似度 = 2/5 = 0.4
Jaccard 距离 = 0.6
```

何时使用 Jaccard：
- 比较标签、类别或特征的集合
- 基于词出现（非频率）的文档相似度
- 近似重复检测（MinHash 对 Jaccard 的近似）
- 比较二进制特征向量（存在/不存在数据）
- 评估分割模型（交并比 = Jaccard）

### 编辑距离（莱文斯坦距离）

编辑距离计算将一个字符串转换为另一个字符串所需的最小单字符操作数。操作是：插入、删除或替换。

```
"kitten" -> "sitting"

kitten -> sitten  （替换 k -> s）
sitten -> sittin  （替换 e -> i）
sittin -> sitting （插入 g）

编辑距离 = 3
```

使用动态规划计算。填充一个矩阵，其中条目 (i, j) 是字符串 A 的前 i 个字符和字符串 B 的前 j 个字符之间的编辑距离。

```
        ""  s  i  t  t  i  n  g
    ""   0  1  2  3  4  5  6  7
    k    1  1  2  3  4  5  6  7
    i    2  2  1  2  3  4  5  6
    t    3  3  2  1  2  3  4  5
    t    4  4  3  2  1  2  3  4
    e    5  5  4  3  2  2  3  4
    n    6  6  5  4  3  3  2  3
```

何时使用编辑距离：
- 拼写检查和纠正
- DNA 序列比对（带加权操作）
- 模糊字符串匹配
- 杂乱文本数据的去重

### KL 散度（不是距离，但被当作距离使用）

KL 散度衡量一个概率分布与另一个的差异程度。在第 09 课中已涵盖，但它属于这里的讨论，因为人们将其用作"距离"，尽管它不是。

```
D_KL(P || Q) = sum(p(x) * log(p(x) / q(x)))
```

关键性质：KL 散度不是对称的。

```
D_KL(P || Q) != D_KL(Q || P)
```

这意味着它不满足距离度量的基本要求。它也不满足三角不等式。它是一个散度，不是一个距离。

前向 KL（D_KL(P || Q)）是"均值寻求"的：Q 试图覆盖 P 的所有模式。
反向 KL（D_KL(Q || P)）是"模式寻求"的：Q 专注于 P 的单一模式。

当你看到 KL 散度时：
- VAE（ELBO 中的 KL 项将潜在分布推向先验）
- 知识蒸馏（学生试图匹配教师的分布）
- RLHF（KL 惩罚使微调后的模型保持在基模型附近）
- 策略梯度方法（约束策略更新）

### Wasserstein 距离（推土机距离）

Wasserstein 距离衡量将一个概率分布转换为另一个所需的最小"功"。把它想象成：如果一个分布是一堆土，另一个是一个坑，你需要移动多少土以及多远？

```
W(P, Q) = 对所有传输计划 gamma 取下确界的 E[d(x, y)]
```

对于 1D 分布，它简化为累积分布函数绝对差的积分：

```
W_1(P, Q) = 积分 |CDF_P(x) - CDF_Q(x)| dx
```

为什么 Wasserstein 很重要：
- 它是一个真正的度量（对称，满足三角不等式）
- 即使分布不重叠也能提供梯度（KL 散度会趋向无穷）
- 这一性质使其成为 Wasserstein GANs（WGANs）的核心，解决了原始 GAN 的训练不稳定性

```
无重叠的分布：

P: [1, 0, 0, 0, 0]    Q: [0, 0, 0, 0, 1]

KL 散度：无穷大（零的对数）
Wasserstein：4（将所有质量移动 4 个箱子）

Wasserstein 给出有意义的梯度。KL 不给出。
```

何时使用 Wasserstein：
- GAN 训练（WGAN、WGAN-GP）
- 比较可能不重叠的分布
- 最优传输问题
- 图像检索（比较颜色直方图）

### 为什么不同任务需要不同距离

| 任务 | 最佳距离 | 原因 |
|------|--------------|-----|
| 文本相似度 | 余弦 | 大小是噪声，方向是含义 |
| 图像像素比较 | L2 | 空间关系重要，特征尺度可比 |
| 稀疏高维特征 | L1 | 鲁棒，不会放大罕见的大差异 |
| 集合重叠（标签、类别） | Jaccard | 数据天然是集合值的，不是向量的 |
| 字符串匹配 | 编辑距离 | 操作映射到人类编辑直觉 |
| 异常检测 | 马氏 | 考虑特征相关性和尺度 |
| 比较分布 | KL 散度 | 衡量使用 Q 替代 P 损失的信息量 |
| GAN 训练 | Wasserstein | 即使分布不重叠也能提供梯度 |
| 嵌入（向量数据库） | 余弦或点积 | 嵌入被训练为将含义编码在方向上 |
| 推荐 | 点积 | 大小可以编码流行度或置信度 |
| DNA 序列 | 加权编辑距离 | 替换代价因核苷酸对而异 |
| 制造质量控制 | L-无穷 | 任何维度中的最坏情况偏差重要 |

### 与损失函数的联系

损失函数是应用于预测 vs 目标的距离函数。

```
损失函数              使用的距离           行为
MSE                  L2 平方             对大误差惩罚很重
MAE                  L1                  平等惩罚所有误差
Huber 损失           对大误差用 L1，       两全其美：对异常值鲁棒，
                     对小误差用 L2        在零附近平滑梯度
交叉熵              KL 散度              衡量分布不匹配
Hinge 损失           max(0, margin - d)  仅在低于间隔时惩罚
Triplet 损失         L2（通常）           拉近正样本，推开负样本
对比损失            L2                   相似对靠近，不相似对超出间隔
```

### 与正则化的联系

正则化向损失函数添加对权重的范数惩罚。

```
L1 正则化（Lasso）：   损失 + lambda * ||w||_1
  -> 稀疏权重。某些权重变为恰好为零。
  -> 自动特征选择。
  -> 解在零点有角（在零处不可微）。

L2 正则化（Ridge）：   损失 + lambda * ||w||_2^2
  -> 小权重。所有权重向零收缩。
  -> 无特征选择（没有任何权重恰好为零）。
  -> 处处平滑的解。

Elastic Net：          损失 + lambda_1 * ||w||_1 + lambda_2 * ||w||_2^2
  -> 结合 L1 的稀疏性和 L2 的稳定性。
  -> 相关特征组被一起保留或一起丢弃。
```

为什么 L1 产生稀疏性而 L2 不产生：想象 2D 权重空间中的约束区域。L1 是菱形，L2 是圆。损失函数的等高线（椭圆）最有可能在菱形的角上接触，那里的一个权重为零。它们在圆的平滑点接触，那里的两个权重都不为零。

### 最近邻搜索

每个距离函数都对应一个最近邻搜索问题：给定一个查询点，在数据集中找到最近的点。

精确最近邻搜索在 n 个点、d 维的数据集中每次查询是 O(n * d)。对于大型数据集，这太慢了。

近似最近邻（ANN）算法以少量精度换取巨大的速度增益：

```
算法               方法                          使用的
KD-trees           轴对齐空间划分                scikit-learn（低维）
Ball trees         嵌套超球                      scikit-learn（中等维度）
LSH                随机哈希投影                  近似重复检测
HNSW               层次可导航小世界图              FAISS、Qdrant、Weaviate
IVF                基于聚类的倒排文件索引           FAISS（十亿级）
Product quant.     压缩向量，在压缩空间中搜索        FAISS（内存受限）
```

HNSW（层次可导航小世界）是现代向量数据库中的主导算法。它构建一个多层图，其中每个节点连接到其近似最近邻。搜索从顶层开始（稀疏，长跳），下降到最底层（密集，短跳）。

## 使用它

最常见的实际用途：在向量数据库中查找相似项目。

```python
import numpy as np

def cosine_similarity_matrix(X):
    norms = np.linalg.norm(X, axis=1, keepdims=True)
    norms = np.where(norms == 0, 1, norms)
    X_normalized = X / norms
    return X_normalized @ X_normalized.T

embeddings = np.random.randn(1000, 768)

sim_matrix = cosine_similarity_matrix(embeddings)

query_idx = 0
similarities = sim_matrix[query_idx]
top_k = np.argsort(similarities)[::-1][1:6]
print(f"与条目 0 最相似的前 5 个: {top_k}")
print(f"相似度: {similarities[top_k]}")
```

当你调用 `model.encode(text)` 然后在向量数据库中搜索时，底层发生的正是这样：嵌入模型将文本映射到向量。向量数据库使用 ANN 算法计算查询向量与每个存储向量之间的余弦相似度（或点积），避免检查所有向量。

## 关键术语

| 术语 | 人们说的 | 实际含义 |
|------|----------------|----------------------|
| 范数 | "向量的大小" | 将向量映射到非负标量的函数，满足三角不等式、绝对齐次性且仅对零向量为零 |
| L1 范数 | "曼哈顿距离" | 各分量绝对值的和。在优化中产生稀疏性。对异常值鲁棒 |
| L2 范数 | "欧几里得距离" | 各分量平方和的平方根。欧几里得空间中的直线距离 |
| Lp 范数 | "广义范数" | 各分量绝对值 p 次幂之和的 p 次根。L1 和 L2 是特例 |
| L-无穷范数 | "最大范数"或"切比雪夫距离" | 最大绝对值分量。Lp 在 p 趋近无穷时的极限 |
| 余弦相似度 | "向量之间的角度" | 被两个大小归一化的点积。范围从 -1 到 +1。忽略向量长度 |
| 余弦距离 | "1 减余弦相似度" | 将余弦相似度转换为距离。范围从 0 到 2 |
| 点积 | "未归一化的余弦" | 逐分量乘积的和。等于余弦相似度乘以两个大小 |
| 马氏距离 | "相关性感知距离" | 在使用数据协方差矩阵白化（去相关和归一化）的空间中的 L2 距离 |
| Jaccard 相似度 | "集合重叠" | 交集大小除以并集大小。用于集合，而不是向量 |
| 编辑距离 | "莱文斯坦距离" | 将一个字符串转换为另一个所需的最少插入、删除和替换 |
| KL 散度 | "分布之间的距离" | 不是真正的距离（不对称）。衡量使用 Q 编码 P 的额外比特数 |
| Wasserstein 距离 | "推土机距离" | 将一个分布的质量运输到另一个分布的最小功。一个真正的度量 |
| 近似最近邻 | "ANN 搜索" | 算法（HNSW、LSH、IVF）以比精确搜索快得多的速度找到近似最近点 |
| HNSW | "向量数据库算法" | 层次可导航小世界图。用于快速近似最近邻搜索的多层图 |
| L1 正则化 | "Lasso" | 将权重的 L1 范数添加到损失中。将权重推向零（稀疏性） |
| L2 正则化 | "Ridge"或"权重衰减" | 将权重的平方 L2 范数添加到损失中。向零收缩权重而不产生稀疏性 |
| Elastic Net | "L1 + L2" | 结合 L1 和 L2 正则化。处理相关特征组比单独使用更好 |

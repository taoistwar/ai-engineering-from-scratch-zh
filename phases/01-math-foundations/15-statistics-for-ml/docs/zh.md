# 机器学习中的统计学

> 统计学告诉你如何判断你的模型是真的有效还是只是运气好。

**类型：** 构建
**语言：** Python
**先决条件：** 阶段 1，第 06 课（概率与分布），第 07 课（贝叶斯定理）
**时间：** ~120 分钟

## 学习目标

- 从头计算描述性统计、Pearson/Spearman 相关性和协方差矩阵
- 执行假设检验（t 检验、卡方检验）并正确解释 p 值和置信区间
- 使用自助重采样为任何度量构造置信区间，无需分布假设
- 使用效应量度量区分统计显著性和实际显著性

## 问题

你训练了两个模型。模型 A 在测试集上得分 0.87。模型 B 得分 0.89。你部署了模型 B。三周后，生产指标比之前更差。发生了什么？

模型 B 实际上并没有优于模型 A。0.02 的差异是噪声。你的测试集太小，或者方差太高，或者两者兼有。你发布了伪装成改进的随机性。

这种情况不断发生。Kaggle 排行榜震荡。无法复现的论文。基于几百个样本就宣布胜者的 A/B 测试。根本原因总是相同的：有人跳过了统计学。

统计学为你提供了区分信号和噪声的工具。它告诉你差异何时是真实的，你该有多确信，以及在信任一个结果之前你需要多少数据。每个 ML 流水线、每个模型比较、每个实验都需要统计学。没有它，你就是在猜测。

## 概念

### 描述性统计：总结你的数据

在对任何东西建模之前，你需要知道你的数据长什么样。描述性统计将数据集压缩为几个捕捉其形状的数字。

**集中趋势的度量**回答"中间在哪里？"

```
均值：   所有值的和 / 数量
          mu = (1/n) * sum(x_i)

中位数： 排序后的中间值
          对异常值鲁棒。如果你有 [1, 2, 3, 4, 1000]，均值是 202
          但中位数是 3。

众数：   最常见的值
          对类别数据有用。对连续数据，很少提供信息。
```

均值是平衡点。中位数是半程标记。当它们偏离时，你的分布是偏斜的。收入分布的均值远大于中位数（来自亿万富翁的右偏）。训练期间的损失分布通常均值远小于中位数（来自简单样本的左偏）。

**离散度的度量**回答"数据有多分散？"

```
方差：   偏离均值的平方的平均
          sigma^2 = (1/n) * sum((x_i - mu)^2)

标准差：方差的平方根
         sigma = sqrt(sigma^2)
         与数据具有相同单位，因此更易于解释。

极差：   max - min
          对异常值敏感。几乎从不单独有用。

IQR：    Q3 - Q1（四分位数间距）
          数据中间 50% 的范围。
          对异常值鲁棒。用于箱线图和异常检测。
```

**百分位数**将排序数据分为 100 等份。第 25 百分位数（Q1）意味着 25% 的值低于此点。第 50 百分位数是中位数。第 75 百分位数是 Q3。

```
对于延迟监控：
  P50 = 中位延迟         （典型用户体验）
  P95 = 第 95 百分位      （较差但不是最坏情况）
  P99 = 第 99 百分位      （尾延迟，通常是中位数的 10 倍）
```

在 ML 中，你关心推理延迟、预测置信度分布和理解误差分布的百分位数。一个平均误差低但 P99 误差糟糕的模型对安全关键应用可能毫无用处。

**样本 vs 总体统计量。** 当从样本计算方差时，除以 (n-1) 而不是 n。这是贝塞尔校正。它补偿了你的样本均值不是真实总体均值的事实。以 n 为分母，你会系统地低估真实方差。以 (n-1) 为分母，估计是无偏的。

```
总体方差：sigma^2 = (1/N) * sum((x_i - mu)^2)
样本方差：s^2     = (1/(n-1)) * sum((x_i - x_bar)^2)
```

在实践中：如果 n 很大（数千个样本），差异可以忽略。如果 n 很小（几十个样本），就有影响。

### 相关性：变量如何一起变化

相关性衡量两个变量之间线性关系的强度和方向。

**Pearson 相关系数**衡量线性关联：

```
r = sum((x_i - x_bar)(y_i - y_bar)) / (n * s_x * s_y)

r = +1:  完美正线性关系
r = -1:  完美负线性关系
r =  0:  无线线性关系（但可能存在非线性关系！）

范围：[-1, 1]
```

Pearson 假设关系是线性的，且两个变量大致是正态分布的。它对异常值敏感。一个极端点可以将 r 从 0.1 拖到 0.9。

**Spearman 秩相关系数**衡量单调关联：

```
1. 将每个值替换为其秩（1, 2, 3, ...）
2. 对秩计算 Pearson 相关系数

Spearman 捕获任何单调关系，不仅仅是线性。
如果 y = x^3，Pearson 给出 r < 1 但 Spearman 给出 rho = 1。
```

**何时使用每种：**

```
Pearson：   两个变量都是连续且大致正态的。
            你特别关心线性关系。
            没有极端异常值。

Spearman：  有序数据（排名、评级）。
            数据不是正态分布的。
            你怀疑是单调但非线性的关系。
            存在异常值。
```

**黄金法则：** 相关性不意味着因果关系。冰淇淋销量和溺水死亡是相关的，因为两者都在夏季增加。你的模型准确率和参数数量是相关的，但增加参数并不自动提高准确率（参见：过拟合）。

### 协方差矩阵

两个变量之间的协方差衡量它们如何一起变化：

```
Cov(X, Y) = (1/n) * sum((x_i - x_bar)(y_i - y_bar))

Cov(X, Y) > 0:  X 和 Y 倾向于一起增加
Cov(X, Y) < 0:  当 X 增加时，Y 倾向于减少
Cov(X, Y) = 0:  没有线性共变
```

对于 d 个特征，协方差矩阵 C 是一个 d x d 矩阵，其中 C[i][j] = Cov(特征_i, 特征_j)。对角线条目 C[i][i] 是每个特征的方差。

```
C = | Var(x1)      Cov(x1,x2)  Cov(x1,x3) |
    | Cov(x2,x1)  Var(x2)      Cov(x2,x3) |
    | Cov(x3,x1)  Cov(x3,x2)  Var(x3)     |

性质：
  - 对称：C[i][j] = C[j][i]
  - 正半定：所有特征值 >= 0
  - 对角线 = 方差
  - 非对角线 = 协方差
```

**与 PCA 的联系。** PCA 对协方差矩阵进行特征分解。特征向量是主成分（最大方差方向）。特征值告诉你每个成分捕获了多少方差。这正是第 10 课的内容，但现在你看到为什么协方差矩阵是正确的分解对象：它编码了数据中所有成对的线性关系。

**与相关性的联系。** 相关矩阵是标准化变量（每个变量除以其标准差）的协方差矩阵。相关性将协方差归一化，使所有值落在 [-1, 1] 中。

### 假设检验

假设检验是一个在不确定性下做决策的框架。你从一个声明开始，收集数据，并确定数据是否与此声明一致。

**设置：**

```
原假设（H0）：         默认假设，通常是"没有效应"
备择假设（H1）：       你试图证明的

例如：
  H0：模型 A 和模型 B 具有相同的准确率
  H1：模型 B 的准确率高于模型 A
```

**p 值**是在假设 H0 为真的情况下，看到与观察到的同等极端数据的概率。它不是 H0 为真的概率。这是统计学中最常见的误解。

```
p 值 = P(数据如此极端 | H0 为真)

如果 p 值 < alpha（通常为 0.05）：
    拒绝 H0。结果是"统计显著的"。
如果 p 值 >= alpha：
    未能拒绝 H0。你没有足够的证据。
    这不意味着 H0 为真。
```

**置信区间**给出参数的可信值范围：

```
均值的 95% 置信区间：
    x_bar +/- z * (s / sqrt(n))

其中 z = 1.96 对应 95% 置信度

解释：如果你多次重复这个实验，95% 的计算区间会包含真实均值。
它不意味着真实均值有 95% 的概率在这个特定区间中。
```

置信区间的宽度告诉你关于精度的信息。宽区间意味着高不确定性。窄区间意味着你的估计是精确的（但如果数据有偏差，则不一定是准确的）。

### t 检验

t 检验比较均值。有几种类型。

**单样本 t 检验：** 总体均值与假设值不同吗？

```
t = (x_bar - mu_0) / (s / sqrt(n))

自由度 = n - 1
```

**双样本 t 检验（独立）：** 两组均值不同吗？

```
t = (x_bar_1 - x_bar_2) / sqrt(s1^2/n1 + s2^2/n2)

这是 Welch's t 检验，它不假设方差相等。
始终使用 Welch's，除非你有特定原因假设方差相等。
```

**配对 t 检验：** 当测量成对出现时（同一模型在相同数据分割上评估）：

```
为每对计算 d_i = x_i - y_i
然后对 d_i 值进行单样本 t 检验，mu_0 = 0
```

在 ML 中，配对 t 检验很常见：你在相同的 10 折交叉验证划分上运行两个模型，并逐对比较它们的得分。

### 卡方检验

卡方检验检查观察频率是否与期望频率匹配。适用于分类数据。

```
chi^2 = sum((观察 - 期望)^2 / 期望)

例如：语言模型的输出分布在类别上是否匹配训练分布？

类别        观察   期望
正面         120    100
负面          80    100
chi^2 = (120-100)^2/100 + (80-100)^2/100 = 4 + 4 = 8

在 1 个自由度下，chi^2 = 8 给出 p < 0.005。
差异是显著的。
```

### ML 模型的 A/B 测试

ML 中的 A/B 测试与 Web A/B 测试不同。模型比较有特定的挑战：

```
1. 相同测试集：    两个模型必须在相同数据上评估。
                     不同的测试集使比较毫无意义。

2. 多个度量：     仅凭准确率是不够的。你需要精确率、
                     召回率、F1、延迟和公平性度量。

3. 方差：        使用交叉验证或自助法来估计
                     每个度量的方差，而不仅仅是点估计。

4. 数据泄漏：     如果测试集在模型选择期间被使用，
                     你的比较是有偏的。保留一个最终测试集。
```

**步骤：**

```
1. 定义你的度量和显著性水平（alpha = 0.05）
2. 在相同的 k 折交叉验证划分上运行两个模型
3. 收集配对分数：[(a1, b1), (a2, b2), ..., (ak, bk)]
4. 计算差值：d_i = b_i - a_i
5. 对差值运行配对 t 检验
6. 检查：均值差异是否显著地不同于 0？
7. 计算均值差异的置信区间
8. 计算效应量（Cohen's d）以判断实际显著性
```

### 统计显著性 vs 实际显著性

一个结果可以是统计显著但实际无意义的。有了足够数据，即使是微小的差异也会变得统计显著。

```
例如：
  模型 A 准确率：0.9234
  模型 B 准确率：0.9237
  n = 1,000,000 测试样本
  p 值 = 0.001

统计显著？是的。
实际显著？0.03% 的改进不值得
部署新模型的工程成本。
```

**效应量**量化差异的大小，与样本量无关：

```
Cohen's d = (mean_1 - mean_2) / 合并标准差

d = 0.2:  小效应
d = 0.5:  中等效应
d = 0.8:  大效应
```

始终报告 p 值和效应量两者。p 值告诉你差异是否真实。效应量告诉你它是否重要。

### 多重比较问题

当你检验许多假设时，一些会偶尔成为"显著"的。如果你以 alpha = 0.05 检验 20 个东西，即使没有任何东西是真实的，你也期望出现 1 个假阳性。

```
P(至少一个假阳性) = 1 - (1 - alpha)^m

m = 20 个检验，alpha = 0.05：
P(假阳性) = 1 - 0.95^20 = 0.64

你有 64% 的机会得到至少一个假阳性。
```

**Bonferroni 校正：** 将 alpha 除以检验次数。

```
调整后的 alpha = alpha / m = 0.05 / 20 = 0.0025

仅在 p 值 < 0.0025 时拒绝 H0。
保守但简单。当检验独立时有效。
```

在 ML 中，当你跨多个度量比较模型、测试许多超参数配置或在多个数据集上评估时，这很重要。

### 自助法

自助法通过有放回地重采样你的数据来估计统计量的抽样分布。不需要对基础分布做假设。

**算法：**

```
1. 你有 n 个数据点
2. 有放回地抽取 n 个样本（某些点出现多次，
   某些完全不出现）
3. 在这个自助样本上计算你的统计量
4. 重复 B 次（通常 B = 1000 到 10000）
5. 自助统计量的分布近似抽样分布
```

**自助置信区间（百分位数方法）：**

```
对 B 个自助统计量排序
95% CI = [第 2.5 百分位数，第 97.5 百分位数]
```

**为什么自助法对 ML 很重要：**

```
- 测试集准确率是一个点估计。自助法给你置信区间。
- 你不能假设度量分布是正态的（尤其对于 AUC、F1、precision at k）。
- 自助法适用于任何统计量：中位数、两个均值的比率、
  两个模型之间 AUC 的差异。
- 不需要封闭形式的公式。
```

**自助法用于模型比较：**

```
1. 你有模型 A 和模型 B 在相同测试集上的预测
2. 对于每次自助迭代：
   a. 有放回地重采样测试索引
   b. 在重采样的集合上计算 metric_A 和 metric_B
   c. 存储 diff = metric_B - metric_A
3. 差异的 95% CI：
   [差值的第 2.5 百分位数，差值的第 97.5 百分位数]
4. 如果 CI 不包含 0，差异是显著的
```

这比配对 t 检验更鲁棒，因为它不做分布假设。

### 参数检验 vs 非参数检验

**参数检验**假设特定分布（通常是正态）：

```
t 检验：         假设正态分布数据（或大 n 通过 CLT）
ANOVA：          假设正态性和方差相等
Pearson r：      假设双变量正态性
```

**非参数检验**不做分布假设：

```
Mann-Whitney U：     比较两组（替代独立 t 检验）
Wilcoxon 符号秩：    比较配对数据（替代配对 t 检验）
Spearman rho：       秩上的相关性（替代 Pearson）
Kruskal-Wallis：     比较多组（替代 ANOVA）
```

**何时使用非参数检验：**

```
- 小样本量（n < 30）且数据明显非正态
- 有序数据（评级、排名）
- 无法移除的严重异常值
- 偏斜分布
```

**何时使用参数检验：**

```
- 大样本量（CLT 使检验统计量近似正态）
- 数据大致对称且没有极端异常值
- 更高的统计效力（更擅长检测真实差异）
```

在 ML 实验中，你通常有小的 n（5 或 10 折交叉验证），因此像 Wilcoxon 符号秩检验这样的非参数检验通常比 t 检验更合适。

### 中心极限定理：实际含义

CLT 说随着 n 增长，样本均值的分布趋近于正态分布，无论基础总体分布如何。

```
如果 X_1, X_2, ..., X_n 是独立同分布的，均值为 mu，方差为 sigma^2：

    X_bar ~ Normal(mu, sigma^2 / n)    当 n -> 无穷

在大多数情况下 n >= 30 就有效。
对于高度偏斜的分布，你可能需要 n >= 100。
```

**为什么这对 ML 很重要：**

```
1. 为聚合度量的置信区间和 t 检验提供了合理性
2. 解释了为什么对交叉验证折取平均会给出稳定
   的估计，即使单个折变化很大
3. 小批量梯度下降有效，因为一个批次上的平均梯度
   近似真实梯度（实践中 CLT 在起作用）
4. 集成方法：对许多模型的预测取平均给出
   比任何单个模型更稳定的输出
```

**CLT 不做什么：**

```
- 不使你的数据正态。它使样本的均值正态分布。
- 对具有无限方差的重尾分布（柯西分布）无效。
- 不适用于依赖数据（没有校正的时间序列）。
```

### ML 论文中常见的统计错误

1. **在训练集上测试。** 保证过拟合。始终保留模型在训练期间从未见过的数据。

2. **没有置信区间。** 报告没有不确定性的单一准确率数字会使结果不可复现和不可验证。

3. **忽略多重比较。** 测试 50 个配置并报告最好那个而不校正，会夸大假阳性率。

4. **混淆统计显著性和实际显著性。** 对一个 0.01% 准确率改进的 p 值 0.001 是没有意义的。

5. **在不平衡数据上使用准确率。** 在 99% 负类的数据集上 99% 准确率意味着模型什么都没学到。使用精确率、召回率、F1 或 AUC。

6. **挑选度量。** 只报告你的模型获胜的度量。诚实的评估报告所有相关度量。

7. **泄漏横跨训练/测试划分的信息。** 在划分之前归一化，或使用未来数据预测过去。

8. **没有方差估计的小测试集。** 在 100 个样本上评估并声称 2% 的改进是噪声，不是信号。

9. **在数据不独立时假设独立性。** 来自同一患者的医学图像，来自同一文档的多个句子。组内的观察是相关的。

10. **P 值操纵。** 尝试不同的检验、子集或排除标准直到得到 p < 0.05。结果是搜索的人为产物。

## 构建它

你将实现：

1. **从头描述性统计**（均值、中位数、众数、标准差、百分位数、IQR）
2. **相关性函数**（Pearson 和 Spearman，以及协方差矩阵）
3. **假设检验**（单样本 t 检验、双样本 t 检验、卡方检验）
4. **自助置信区间**（用于任何统计量，不需要假设）
5. **A/B 测试模拟器**（生成数据，测试，检查 I 型和 II 型错误）
6. **统计 vs 实际显著性演示**（展示大 n 使一切都"显著"）

全部从零实现，仅使用 `math` 和 `random`。不使用 numpy，不使用 scipy。

| 均值 | 值的和除以数量。对异常值敏感。 |
| 中位数 | 排序数据的中间值。对异常值鲁棒。 |
| 标准差 | 方差的平方根。以原始单位测量离散度。 |
| 百分位数 | 给定百分比的数据低于的值。 |
| IQR | 四分位数间距。Q3 减 Q1。中间 50% 的离散度。 |
| Pearson 相关性 | 衡量两个变量之间的线性关联。范围 [-1, 1]。 |
| Spearman 相关性 | 使用秩衡量单调关联。 |
| 协方差矩阵 | 所有特征之间成对协方差的矩阵。 |
| 原假设 | 无效应或无差异的默认假设。 |
| p 值 | 在原假设为真的情况下，数据如此极端的概率。 |
| 置信区间 | 在给定置信水平下参数的可信值范围。 |
| t 检验 | 检验均值是否显著不同。使用 t 分布。 |
| 卡方检验 | 检验观察频率是否与期望频率不同。 |
| 效应量 | 差异的大小，与样本量无关。Cohen's d 是常见的。 |
| Bonferroni 校正 | 将显著性阈值除以检验次数以控制假阳性。 |
| 自助法 | 有放回重采样以估计抽样分布。 |
| I 型错误 | 假阳性。在 H0 为真时拒绝它。 |
| II 型错误 | 假阴性。在 H0 为假时未能拒绝它。 |
| 统计效力 | 正确拒绝虚假 H0 的概率。效力 = 1 减 II 型错误率。 |
| 中心极限定理 | 随着样本量增长，样本均值收敛到正态分布。 |
| 参数检验 | 假设数据有特定分布（通常是正态）。 |
| 非参数检验 | 不做分布假设。在秩或符号上工作。 |

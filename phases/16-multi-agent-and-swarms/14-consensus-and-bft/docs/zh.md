# 共识与智能体拜占庭容错

> 经典分布式系统BFT遇见随机LLM。2025-2026年出现了三个研究方向：**CP-WBFT**（arXiv:2511.10400）通过置信度探针为每票加权；**DecentLLMs**（arXiv:2507.14928）以并行工作者提案和几何中位数聚合实现无领导者；**WBFT**（arXiv:2505.05103）结合加权投票与层次结构聚类以拆分核心和边缘节点。来自"Can AI Agents Agree?"（arXiv:2603.01213）的诚实经验结果是，即使是标量一致性在今天也是脆弱的——单一欺骗性智能体可以破坏智能体混合体。BFT是必要的但不充分。本课构建极简BFT协议，注入三种智能体特定攻击（拜占庭谎言、谄媚一致性、相关错误单一文化），并测量每种共识变体如何应对。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 07 (Society of Mind and Debate), Phase 16 · 13 (Shared Memory)
**Time:** ~75 minutes

## 问题

你有N个LLM智能体，每个产生一个答案。它们不一致。多数投票选错了，因为两个智能体是相关的（相同基础模型、相同训练数据、相同失败模式）。第三个智能体恰好以新颖方式错了——因此多数是假多数。

现在添加一个欺骗性智能体：它故意撒谎。或一个谄媚智能体：它同意最后一个发言者。在经典BFT中，假设拜占庭节点是 `f < n/3` 的分数并任意行为。2026年的现实是LLM节点即使在诚实时也是随机的，跨模型相关，并被彼此的输出影响。你不能将其视为独立伯努利投票者。

经典BFT（PBFT，1999年）不是错误的——它是不完整的。它处理任意位翻转。它不处理"三个诚实智能体共享幻觉因为它们共享训练数据。"本课从PBFT的基础构建并在其上叠层三种2025-2026年适应。

## 概念

### 经典BFT给你什么

实用拜占庭容错（Castro & Liskov, OSDI 1999）容忍 `f < n/3` 拜占庭节点。协议有三个阶段（预准备、准备、提交）和两个原语（签名消息、法定人数证书）。在 `n >= 3f + 1` 诚实或恶意节点中对单一值达成一致。

保证很强但假设：

1. **独立故障。** 拜占庭节点不协调。
2. **诚实节点真正诚实。** 诚实输出的正确性不是问题；协议仅对齐分歧。
3. **问题有真地答案。** 对错误事实的共识仍然是共识。

LLM智能体违反全部三项。两个运行相同基础模型的智能体共享故障。一个"诚实"LLM仍然幻觉。而在模糊问题上，"真相"是智能体决定的——没有外部预言机。

### 三种LLM特定攻击

**拜占庭谎言。** 一个智能体输出故意错误答案。如果 `f < n/3`，经典BFT处理这一点。

**谄媚一致性。** 一个智能体在投票前阅读其他人答案，与最后一个发言者对齐。不恶意，但与最大声音相关。经典BFT不能防止这一点，因为智能体通过每个签名检查。

**相关错误单一文化。** 三个智能体共享基础模型。它们幻觉相同错误答案。多数是错误的。经典BFT无助，因为所有三个"诚实地"同意。

### 2025-2026年回应

**CP-WBFT**（arXiv:2511.10400）——置信度探测加权BFT。每个投票者对其答案附加置信度探针（自我报告概率，或单独校准模型的预测）。投票权重随置信度缩放。报告在完整图上有+85.71%的BFT改进。缓解：谄媚一致性（趋向于其自愿立场的低置信度）。

**DecentLLMs**（arXiv:2507.14928）——无领导者。工作者智能体并行提案，评估者智能体评分提案，最终答案是评分位置的几何中位数。当 `f < n/2` 时鲁棒。缓解：拜占庭谎言和相关错误（几何中位数对异常值鲁棒，拉向稠密簇，而非模型偏置的平均值）。

**WBFT**（arXiv:2505.05103）——带层次结构聚类的加权BFT。投票权重由响应质量加从历史学习的信任分数分配。将智能体聚类为核心和边缘；核心智能体必须首先达成共识，边缘智能体跟随。缓解：可扩展性（核心共识小而快），部分针对单一文化（核心可以选择为多样性）。

### 经验性："Can AI Agents Agree?"（arXiv:2603.01213）

论文跨多个前沿模型测量标量一致性（LLM智能体对单一数值达成共识）。发现令人不安：

- 即使没有对手，LLM智能体在许多基准上对标量问题的不一致率超过30%。
- 单一采用欺骗性角色的智能体可以将智能体混合体共识从诚实基线拉开40+个百分点。
- 不一致率与模型多样性相关——异构集合比同质的有更多不一致（好：不相关错误），但也漂移更慢（坏：更长的一致时间）。

结论：BFT给你对齐输出的机制，但它不告诉你对齐的输出是否正确。与验证（第16阶段·第08课 角色专门化）、多样性（第16阶段·第15课 辩论变体）和评估者智能体（第16阶段·第24课 基准）结合。

### 核心协议，精简

针对LLM智能体的极简BFT轮：

```
1. 任务到达；每个智能体i产生答案a_i
2. 每个智能体附加置信度探针c_i in [0, 1]
3. 聚合器从所有n个智能体收集(a_i, c_i)
4. 聚合器按语义簇分组（等价答案）
5. 聚合器为每个簇C计算权重：
     w(C) = sum_{i in C} c_i
6. 获胜者 = 最大权重的簇，如果 max > threshold * sum(c_i)
   否则：重试或升级
7. 少数派簇带来源记录以供事后审计
```

语义聚类步骤是LLM特定转折。两个答案 "the study reports 4.2%" 和 "4.2% improvement" 是同一个簇。天真的字符串相等检查会遗漏这一点。在生产中，使用廉价嵌入模型或显式标准化。

### 阈值调优

`threshold` 参数决定何时接受、何时重试。太低：你接受弱多数。太高：你从不接受任何东西。经验范围：对 `n=5-7` 智能体为0.5-0.67，对更小 `n` 更高。低于阈值，升级给人类或不同智能体集合。

### 共识在哪里无帮助

- **模糊问题。** 如果问题没有真地，共识是意见。称之为意见。
- **复合问题。** "写代码并解释它"——两个答案。独立对每个投票。
- **对抗多轮。** 如果智能体可以观察先前轮次并模仿（Du 2023辩论），它们开始彼此同意而不管真相。限制轮次（通常2-3轮）。

## 构建它

`code/main.py` 实现：

- `AgentVoter`——带（答案，置信度）的脚本化策略。
- `MajorityVote`——经典多数。
- `CPWBFT`——带语义聚类的置信度加权投票。
- `DecentLLMs`——评分提案上的几何中位数聚合。
- `Scenario`——在三种攻击模式下运行每种聚合器。

实现的攻击模式：

1. `byzantine`：一个智能体以高置信度撒谎。
2. `sycophancy`：一个智能体复制其看到的第一个答案，匹配置信度。
3. `monoculture`：三个智能体共享一个错误答案（相关错误）带中等置信度。

运行：

```
python3 code/main.py
```

预期输出：一个（攻击，聚合器）→ 最终答案的表格，正确答案突出显示。多数在单一文化案例中失败。CPWBFT的置信度加权缓解谄媚。当单一文化小于人口一半时，DecentLLMs的几何中位数拉向诚实簇。

## 交付物

在交付任何共识机制之前：

- **至少用上述三种模式进行攻击测试。** 你的协议应可预测地失败，而非默默失败。
- **带来源记录每个少数派簇。** 少数派簇是你相关错误的预警系统。
- **强制限制轮次。** 不"持续辩论直到一致"——那奖励谄媚。
- **将一致性从正确性中分离。** 共识输出传给验证者；验证者独立于集合。
- **监控一致率。** 急剧上升意味着一��性偏差；急剧下降意味着模型漂移。

## 练习

1. 运行 `code/main.py`。确认多数在单一文化攻击中失败，但当单一文化置信度低于0.7时CPWBFT部分缓解。
2. 添加第四种攻击模式：**静默弃权**——一个智能体拒绝回答（"我不知道"）。每种聚合器应如何处理弃权？实现你的选择。
3. 将语义聚类从字符串标准化切换为嵌入相似度（使用任何开源嵌入模型）。谄媚攻击上发生什么？
4. 阅读CP-WBFT（arXiv:2511.10400）。实现置信度探针校准步骤（独立校准模型检查每个智能体的自我报告置信度）。测量单一文化场景上的准确率增益。
5. 阅读"Can AI Agents Agree?"（arXiv:2603.01213）。复现一个简化的标量一致性实验：三个智能体，一个标量问题，欺骗性角色提示。CPWBFT或DecentLLMs捕获它吗？

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| BFT | "拜占庭容错" | Castro-Liskov 1999年協議，对 `f < n/3` 任意故障达成共识。 |
| 拜占庭 | "任何不良行为" | 一个可以撒谎、丢弃消息、静默失败的节点——除安全崩溃外的任何行为。 |
| 置信度探针 | "你有多确定？" | 附加到投票的自我报告或校准器预测的概率。 |
| 语义聚类 | "相同答案，不同措辞" | 计数投票前对等价答案分组。 |
| 几何中位数 | "鲁棒中心" | 最小化到采样点距离和的点。对异常值鲁棒，不像均值。 |
| 单一文化 | "相同模型，相同失败" | 当智能体共享训练数据或基础模型时的相关错误。 |
| 谄媚一致性 | "与最大声音一致" | 智能体的投票偏向第一个/最响发言者。 |
| 核心/边缘 | "层次BFT" | WBFT分裂：小核心共识优先，边缘节点跟随。限制延迟。 |

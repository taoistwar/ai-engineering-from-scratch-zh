# 智能体经济、Token激励、声誉

> 长周期自主智能体（METR的1小时到8小时工作曲线）需要经济代理能力。新兴的**5层技术栈**是：**DePIN**（物理计算）→ **身份**（W3C DID + 声誉资本）→ **认知**（RAG + MCP）→ **结算**（账户抽象）→ **治理**（智能体DAO）。生产中的智能体激励网络包括**Bittensor**（TAO子网奖励任务特定模型）、**Fetch.ai / ASI联盟**（ASI-1 Mini LLM + FET代币）和**Gonka**（基于Transformer的PoW将计算重新分配给生产性AI任务）。学术工作：AAMAS 2025的去中心化LaMAS使用**Shapley值信用归属**公平奖励贡献智能体；Google Research的"大型语言模型的机制设计"提出单调聚合下的**第二价格拍卖**token拍卖。本课构建极简智能体市场，将Shapley值信用归属应用于多智能体流水线，并运行第二价格token拍卖使博弈论机制具体落地。

## 问题

当智能体共同产生价值但需要被单独奖励时，多智能体系统变得复杂。经典机制——均分、最后贡献者拿走全部——不公平或可博弈。基于Shapley值的联盟奖励通过构造公平但计算昂贵。2025-2026年文献推进有用的近似：Shapley采样、单调聚合拍卖和从确认贡献中累积的链上声誉。

超越信用归属，该领域已转向实际经济智能体：Bittensor TAO奖励挖矿计算来微调子网特定模型，Fetch.ai/ASI用FET代币奖励ASI-1 Mini LLM使用，Gonka将Transformer工作量证明重新分配到生产性AI任务。自主交易的智能体今天已存在；问题是如何对齐激励。

本课将智能体经济视为特定问题族——信用归属、机制设计和声誉——并用最少数学构建每个使想法植根。

## 概念

### 5层智能体经济技术栈

1. **DePIN（物理计算）。** 出租GPU、存储、带宽的去中心化基础设施。Bittensor子网、Render Network、Akash。非智能体特定；智能体使用它。
2. **身份。** W3C去中心化标识符（DID）给每个智能体一个独立于任何平台的持久ID。声誉累积到DID。智能体网络协议（ANP）使用DID作为发现层。
3. **认知。** 智能体的推理循环：LLM + RAG + MCP。这是其他阶段构建的。
4. **结算。** 账户抽象（ERC-4337）允许智能体从自己的余额支付gas而不持有ETH。智能体可以为服务、彼此或计算付费。
5. **治理。** 智能体DAO：人类*和*智能体对协议更改投票的治理结构，投票权与声誉绑定。

并非每个生产系统使用全部五层。Bittensor使用1、2、部分3、部分4，没有5。OpenAI智能体除3外不使用任何。技术栈是参考地图，非要求。

### Bittensor、Fetch.ai、Gonka——什么在运行

**Bittensor（TAO）。** 子网是专门化任务（语言建模、图像生成、预测）。矿工提交模型输出。验证者排名它们；质押加权评分分配TAO奖励。每个子网有自己的评估。经济经验教训：支付任务特定输出质量，而非使用的计算。

**Fetch.ai / ASI联盟。** ASI-1 Mini LLM在Fetch.ai网络上运行；用户为推理支付FET代币。此处智能体作为对等体的叙事更强：Fetch上的智能体可以为任务调用另一个并以FET支付。

**Gonka。** Transformer工作量证明："工作"是Transformer的前向传递。矿工通过运行已知正确输出（来自训练数据）的推理任务赚取。资源生产性PoW而非基于哈希的PoW。

截至2026年4月，三者都是生产级别。收益分配不同。Bittensor奖励相对子网验证者的质量；Fetch奖励以付费用户衡量的效用；Gonka奖励可验证的推理工作。

### Shapley值信用归属

三个智能体协作完成任务。输出得分0.8。谁贡献了什么？

Shapley值：满足四个公理（效率、对称性、线性、零）的唯一信用分配。对于智能体`i`：

```
shapley(i) = (1/N!) * 对所有排序O求和 v(S_i_O ∪ {i}) - v(S_i_O)
```

其中`S_i_O`是排序`O`中`i`之前的智能体集合。实践上：枚举所有排列，记录每个智能体在每个排列中的边际贡献，取平均。

对于N=3个智能体，有6种排列。对于N=10，360万——因此实践中采样而非枚举排序。

### 聚合的第二价格拍卖

Google Research（"大型语言模型的机制设计"）提出用于聚合LLM输出的第二价格token拍卖。设置：N个智能体各提议一个完成；每个有被选中的私人价值。拍卖者选择最高价值提案，支付*第二高*价值。在单调聚合下（价值取决于哪个提案被选中，而非多少提案被投标），这是诚实的——智能体投标其真实价值。

为什么这对LLM系统重要：你可以将完成任务外包给不同定价的多个智能体；拍卖选择最好并公平支付，智能体没有动机虚假报告。

### 声誉资本

DID绑定的声誉分数从确认贡献中累积。简单更新规则：

```
rep(i, t+1) = alpha * rep(i, t) + (1 - alpha) * contribution_quality(i, t)
```

衰减因子`alpha`接近1。声誉：

- 对路由决策读取廉价（"将困难任务发送给高声誉智能体"）。
- 伪造昂贵（随时间累积，绑定到DID）。
- 可被削减：验证失败的贡献减去。

### AAMAS 2025去中心化LaMAS

LaMAS提案（AAMAS 2025）结合：DID身份、Shapley值信用归属和简单拍卖机制。关键声称：去中心化信用归属步骤使系统可审计且免疫单点操纵。

### 经济学在哪里崩溃

- **价格预言机操纵。** 如果信用函数可被博弈，智能体会博弈它。每个机制需要对抗测试。
- **女巫攻击。** 一个操作者启动N个假智能体夸大自己的贡献。DID减慢但不止此；声誉成本抵御伪造是缓解措施。
- **验证成本。** 信用归属仅与验证者一样公平。如果验证廉价（小LLM），可被博弈；如果昂贵（人类小组），系统不扩展。
- **监管积压。** 智能体经济与金融监管交叉。Bittensor、Fetch和Gonka截至2026年都在一些司法管辖区处于法律灰色地带。

### 何时智能体经济有意义

- **具有异构操作者的开放网络。** 没有单一团队控制所有智能体。
- **可验证输出。** 没有验证，信用归属是猜测。
- **长周期工作流。** 一次性任务不���益于声誉累积。
- **代币化支付在你的司法管辖区法律可行。**

在封闭企业系统中，经济学让位于更简单分配（管理者分配工作，指标是内部的）。经济学文献主要适用于开放网络。

## 交付物

2026年运行智能体经济：

- **从声誉开始，非代币。** 声誉实现廉价且自身有价值；代币添加法律和经济复杂性。
- **先验证再奖励。** 永不无独立验证步骤分配信用。自我报告质量累积女巫博弈。
- **Shapley采样，非Shapley精确。** 采样100-1000种排序；精确枚举不扩展。
- **上限衰减因子和下限声誉。** 无界衰减抹去合法贡献者；过慢衰减奖励陈旧高声誉智能体。
- **对抗性审计机制。** 在开放网络前运行红队场景。每个机制都有博弈论；你要找漏洞，而非攻击者。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| DePIN | "去中心化物理基础设施" | 代币激励的计算/存储/带宽。Bittensor、Akash、Render。 |
| DID | "去中心化标识符" | W3C可移植ID规范。智能体声誉绑定到DID，非平台。 |
| ERC-4337 | "账户抽象" | 可赞助gas的合约账户，启用智能体支付。 |
| Shapley值 | "公平信用归属" | 满足效率、对称性、线性、零的唯一分配。 |
| 第二价格拍卖 | "Vickrey拍卖" | 诚实机制：获胜者支付第二高投标。单调聚合兼容。 |
| 声誉资本 | "累积质量分数" | 从确认贡献中累积的DID绑定分数；随时间衰减。 |
| 智能体DAO | "智能体+人类治理" | 智能体投票者作为一等的DAO，投票权与声誉绑定。 |
| TAO / FET / GPU信用 | "代币面额" | Bittensor TAO、Fetch.ai FET、各种DePIN代币。 |

# 生成式智能体与涌现模拟

> Park等人2023年（UIST '23，arXiv:2304.03442）用三部分架构填充了**Smallville**，一个25个智能体的沙盒：**内存流**（自然语言日志）、**反思**（智能体对自身流产生的更高层综合）和**计划**（日级行为，然后是子计划）。标志性结果是情人节派对涌现：一个智能体播种了"想举办情人节派对"，没有进一步脚本，产生了在人群中传播的邀请、协调日期，派对发生了——来自24个最初对其一无所知的智能体。消融实验显示所有三个组件对可信度都是必需的。有记录的失败是空间规范错误（进入关闭的商店、共享单人卫生间）。这是2026年智能体模拟和多智能体社会评估的参考架构。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model), Phase 16 · 13 (Shared Memory)
**Time:** ~75 minutes

## 问题

大多数多智能体系统是严格脚本化的团队：规划者规划，编码者编码，审阅者审查。这对定义明确的任务有效。它不捕获当智能体具有内存、优先级和开放世界时产生的涌现、无脚本行为。研究、社会模拟以及越来越��的游戏AI需要这第二种。

Smallville架构是其基准。在Park 2023年之前，最好的智能体模拟是浅脚本追随者；之后，该模式是开放世界中生成式智能体的默认模式。如果你在2026年构建智能体模拟，你要么在使用Smallville的三个组件，要么在显式论证为什么不使用。

## 概念

### 三个组件

**内存流。** 观察、行动、反思和计划的仅追加日志。每个条目有时间戳、类型、描述（自然语言），以及派生元数据：**新近度**、**重要性**（智能体自我评分1-10）和**相关性**（与当前查询的余弦相似度）。

```
[2026-02-14 09:12:03] observation: Isabella Rodriguez asked me if I like jazz
[2026-02-14 09:14:22] reflection:   I enjoy long conversations about music
[2026-02-14 10:05:00] plan:         Attend Isabella's Valentine's Day party tonight
```

内存检索结合三个分数：`score = w_recency * e^(-decay * age) + w_importance * importance + w_relevance * cos_sim`。Top-k条目进入当前提示。

**反思。** 周期性（每N条内存或重要事件时），智能体从最近内存生成更高阶综合。反思条目回到流中并像任何其他内存一样可检索。这是智能体构建"理解"的方式——架构的长���信念等价物。

**计划。** 自上而下分解。首先，日级计划大笔勾勒（"上班，与Klaus吃晚餐"）。然后小时级计划。然后行动级计划。计划可修改：当观察与计划矛盾时，智能体重新规划受影响的部分。

### 为什么三者都重要（消融实验）

Park等人运行消融实验，分别移除观察、反思和计划。每次消融损害可信度：

- 没有**观察**智能体错过上下文并对陈旧信念行动。
- 没有**反思**智能体无法形成更高阶信念；互动保持浅层。
- 没有**计划**行为变为反应性噪声；目标消散。

来自人类评分者的可信度分数在三者都存在时最高；移除任何一者产生可测量的退步。

### 情人节涌现

一个智能体，Isabella Rodriguez，被播种目标"想在2月14日下午5点在Hobbs Cafe举办情人节派对。"其他24个智能体没有收到此类种子。在模拟的天数中：

1. Isabella的计划包含邀请人。
2. 每次邀请成为邻居内存流中的观察。
3. 该邻居的反思生成信念："Isabella在举办派对。"
4. 邻居的计划纳入"2月14日参加派对。"
5. 邻居告诉其他邻居。邀请在没有中央协调的情况下传播。
6. 2月14日下午5点，几个智能体在Hobbs Cafe聚集。

这是技术意义上的涌现：系统级行为（一个派对）从局部互动（双边邀请 + 个人计划）中产生，没有中央编排者。

### 有记录的失败模式

Park等人显式记录：

- **空间规范错误。** 智能体走进关闭的商店。智能体尝试使用同一个单人卫生间。智能体在非用餐房间进食。模型不单从环境推断社会物理规范。
- **内存溢出。** 深度模拟运行导致内存检索成本增长。实际补救：周期性内存压缩（摘要并剪枝）和低重要性条目的衰减。
- **反思幻觉。** 反思可能发明不存在于内存流中的关系。缓解：在反思提示中包含来源内存ID，并在检索时验证。

这些是生产相关的失败模式：任何2026年智能体模拟都继承它们。

### 三组件实现规则

1. **内存是仅追加的。** 永不改变内存条目。修正是新条目。
2. **重要性分数廉价。** 在写入时调用LLM按1-10评分重要性。缓存分数。
3. **检索是排序的，非过滤的。** 按组合分数的Top-k；不要使用硬过滤器（丢失上下文）。
4. **反思周期性运行。** 当未处理内存的重要性之和超过阈值时触发（例如150）。
5. **计划是可修改的。** 当新观察与计划矛盾时，仅重新生成受影响的部分，而非整个计划。

### Smallville之外的生成式智能体

2024-2026年后续文献扩展了架构：

- **用于政策/市场研究的多智能体社会模拟。** Smallville类似群体模拟用户对功能的响应。比A/B测试快；准确率有争议。
- **游戏的NPC AI。** 带Smallville智能体的RPG产生涌现故事线而非脚本化任务。
- **生成式智能体评估基准。** 指标不是任务准确率，而是长时间运行的行为可信度 + 连贯性。

该架构是参考。扩展交换组件（向量存储用于内存、检索增强反思、神经符号计划）但保持三部分结构。

### 这对多智能体工程为什么重要

Smallville是概念验证，即当组件正确时多智能体涌现很廉价。该架构现已在开源模型上复现（较小的LLM优雅而非急剧丢失可信度）。任何需要**涌现社会行为**的生产系统使用此形状。任何需要**紧密任务执行**的系统使用本阶段前面部分的监督者/角色/原语模式。

## 构建它

`code/main.py` 在标准库Python中用脚本化智能体策略（无真实LLM）实现三组件。演示复现微型情人节派对涌现：

- `MemoryStream`——带新近度/重要性/相关性检索的仅追加日志。
- `reflect(stream)`——对最近高重要性内存的脚本化反思。
- `plan(agent_state)`——基于当前信念的日级和小时级计划。
- 场景：5个智能体。智能体1以"下午5点举办派对"开始。在模拟刻度中，邀请传播，智能体聚集。

运行：

```
python3 code/main.py
```

预期输出：逐刻追踪。到最终刻度，5个智能体中至少3个在计划中显示派对，它们聚集在派对地点。单一种子产生了协调到达，无需任何编排者。

`outputs/skill-simulation-designer.md` 设计生成式智能体模拟：智能体数量、内存模式、反思频率、计划视界和评估指标。

## 交付物

生产模拟规则：

- **内存是数据库。** 在规模上选择真实存储（向量DB、Postgres）。内存中标准库用于原型。
- **记录检索追踪。** 对每次行动，记录驱动它的top-k内存。这是你的调试能力。
- **预算每个智能体token。** 每个智能体每刻度的retrieve + reflect + plan是O(k) LLM调用。N个智能体 × T个刻度 × 每刻度调用可以压倒你的预算。
- **周期性压缩内存。** 摘要并剪枝低重要性条目。保留策略是设计决策，而非细节。
- **显式检测空间/社会规范违规。** 架构不学习它们。

## 练习

1. 运行 `code/main.py`。确认3+个智能体在派对上聚集。增加到10个智能体——涌现仍然发生吗？
2. 移除反思步骤。行为是什么样子？映射到Park 2023年消融发现。
3. 引入竞争性播种目标（"Klaus想在下午5点做研究报告"）。智能体分��吗，还是一个目标占主导？什么决定它？
4. 添加空间约束：Hobbs Cafe最多容纳4个智能体。模拟是否优雅处理溢出，还是触及"单人卫生间"失败模式？
5. 阅读Park等人（arXiv:2304.03442）第6节（涌现行为实验）。识别一种在你的微型模拟中不可复现的行为。你需要增强架构的哪个组件？

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| 内存流 | "智能体的日记" | 观察、行动、反思、计划的仅追加日志。 |
| 新近度 | "内存有多新" | 按年龄的指数衰减分数。 |

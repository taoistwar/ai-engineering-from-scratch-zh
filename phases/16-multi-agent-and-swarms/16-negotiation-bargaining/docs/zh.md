# 协商与讨价还价

> 智能体协商资源、价格、任务分配和条款。2026年基准集很清晰：NegotiationArena（arXiv:2402.05863）显示LLM可以通过角色操纵（"绝望"）将收益改善约20%；"Measuring Bargaining Abilities"（arXiv:2402.15813）显示买方比卖方更难，规模无帮助——他们的**OG-Narrator**（确定性要约生成器 + LLM叙述者）将成交率从26.67%推至88.88%；大规模自主协商竞赛（arXiv:2503.06416）运行约18万次协商，发现**隐藏思维链**的智能体通过向对手隐藏推理获胜；Bhattacharya等人2025年基于哈佛谈判项目指标将Llama-3评为最有效、Claude-3为最激进、GPT-4为最公平。本课实现合同网协议（FIPA祖先，第02课），连接LLM风格买方/卖方，运行OG-Narrator风格分解，并测量成交率随每个结构选择如何变化。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 02 (FIPA-ACL Heritage), Phase 16 · 09 (Parallel Swarm Networks)
**Time:** ~75 minutes

## 问题

两个智能体需要就价格达成一致。留给自己用纯语言提示时，2024-2026年LLM以惊人低的速度达成交易（在arXiv:2402.15813的严格参数化讨价还价中约27%）。规模不修复它：GPT-4在讨价还价的结构能力上不比GPT-3.5更好；它在讨价还价的*语言*上更好。

根本问题是LLM将两项工作混为一谈——决定要约和叙述要约。OG-Narrator将它们分离：确定性要约生成器计算数字移动；LLM仅叙述。成交率跃升至约89%。

这映射经典多智能体发现：将机制与通信层解耦获胜。合同网协议（FIPA，1996年；Smith，1980年）是参考任务市场机制。将LLM插入叙述位置，你得到现代LLM驱动的任务市场。

## 概念

### 合同网，一段话概括

Smith 1980年合同网协议：**管理者**广播**征集提案（cfp）**；**投标者**以包含其要约的**propose**消息回应；管理者选择一个获胜者并向获胜者发送**accept-proposal**，向失败者发送**reject-proposal**。获胜者执行工作。可选消息：**refuse**（投标者拒绝提案）。FIPA将此编纂为`fipa-contract-net`交互协议。

### 为什么OG-Narrator获胜

"Measuring Bargaining Abilities of Language Models"（arXiv:2402.15813）观察到：

- LLM经常破坏讨价还价规则（在荒谬价格做出要约，忽略对方的ZOPA）。
- 它们锚定差（接受坏的第一要约；以象征性而非战略性金额做出反驳）。
- 规模单独不修复这些。更大模型以类似战略错误产生更合理的语言。

OG-Narrator分解：

```
           ┌──────────────────┐        ┌──────────────────┐
  状态 →  │    要约生成器      │ 价格 → │   LLM叙述者       │ → 消息
           │  （确定性的）      │        │  （编写人类风格     │
           │                  │        │   的伴随文本）     │
           └──────────────────┘        └──────────────────┘
```

要约生成器是经典协商策略：Rubinstein讨价还价模型、Zeuthen策略或价格上简单的以牙还牙。LLM叙述。消息包含确定性价格和自然语言框架。

成交率跃升因为：
- 价格保持在讨价还价区域内。
- 锚点是战略性的，非情绪性的。
- LLM做它擅长的：写作。

### NegotiationArena发现

arXiv:2402.05863提供权威基准。头条发现：

- LLM可以通过采用角色（"我绝望地想在周五前卖掉这个"）将收益改善约20%——角色操纵是真实策略。
- 公平/合作智能体被对抗性智能体利用；防御需要显式反姿态。
- 对称配对在约40%的基准场景上收敛到不公平结果。

这不是"LLM是差谈判者。"这是"LLM谈判太像人类了，包括可被利用的部分。"

### 思维链隐藏

大规模自主协商竞赛（arXiv:2503.06416）跨许多LLM策略运行约18万次协商。获胜者向对手隐藏其推理：

- 如果智能体将"我只会到75美元；我的保留价是70美元"打印到公开便签，对手读取它。
- 获胜者私下计算策略；输出通道仅包含要约和最少必要叙述。

这是古典博弈论（Aumann 1976年关于理性和信息）的2026年回响：透露你的私人估值有损收益。LLM不会直觉这一点，并愉快地在推理追踪中输入其保留价，这些追踪对对手可见。

工程启示：将私人便签上下文与公开消息上下文分离。不可选。

### Bhattacharya等人2025年——模型排名

基于哈佛谈判项目指标（原则性谈判、BATNA尊重、利益互惠）：

- **Llama-3**是达成交易最具效果的（成交率 + 收益）。
- **Claude-3**是最激进的谈���者（高锚点、迟让步）。
- **GPT-4**是最公平的（跨配对的收益方差最小）。

这是2025年快照。重点不是哪个模型在2026年4月获胜——而是不同基础模型有持久的谈判风格。异构集成（第15课）将此作为多样性来源。

### 通过合同网 + LLM的任务分配

合同网对LLM多智能体的现代重用：

1. 管理智能体将任务分解为单元。
2. 广播带有任务描述的`cfp`给工作者智能体。
3. 每个工作者返回要约：`(price, eta, confidence)` 其中price可以是tokens、计算单元或美元。
4. 管理者选择获胜者（单一或多个，取决于任务）并授予。
5. 被拒绝的工作者可以自由竞标其他任务。

这扩展到超过100个工作者，因为协调是广播-响应，而非同步聊天。在生产中使用：Microsoft Agent Framework的编排模式，一些LangGraph实现。

### LLM利益相关方交互协商

NeurIPS 2024引入带**秘密分数**和**最低接受阈值**的多方可评分博弈。每个利益相关方有私人效用；LLM必须从消息中推断它们。这是两方讨价还价到N方联盟形成的泛化。与具有异构工作者能力的生产任务市场相关。

### 叙述-对-机制规则

跨所有2024-2026年协商基准，一致的工程规则是：

> 让LLM叙述。不要让LLM计算要约。

如果要约需要是数字（价格、ETA、数量），从协商状态确定性地生成它，让LLM产生框架。如果要约需要是提案结构（任务分解、角色分配），让LLM起草它，但在发送前根据模式和约束检查验证它。

## 构建它

`code/main.py` 实现：

- `ContractNetManager`、`ContractNetTask`、`Bid`——管理者 + 投标者，广播cfp，收集提案，授予。
- `og_narrator_bargain(state, rng)`——OG-Narrator买方：确定性Zeuthen风格向中点让步。
- `seller_response(state, rng)`——确定性卖方反驳策略（两者风格的结构真地）。
- `naive_llm_bargain(state, rng)`——模拟全LLM讨价还价者：以高方差选择价格，常在ZOPA外。
- 测量：1000次试验的成交率，每次试验采用新鲜保留价。

运行：

```
python3 code/main.py
```

预期输出：天真LLM成交率~65-75%；OG-Narrator成交率~85-95%；15-25点差距是将要约生成从叙述中分解的结构优势。加上带三个投标者和一个任务的合同网任务市场分配示例。

## 交付物

生产讨价还价检查清单：

- **分离便签。** 私人状态永不到达对手上下文。这是不可协商的。
- **确定性要约生成。** 价格、数量、ETAs：计算，不要提示。
- **根据模式验证所有到达要约。** 在协议边界拒绝超出ZOPA的要约。
- **限制轮数。** 最多3-5轮；死锁时升级给调解者。
- **持续测量成交率和收益方差。** 下降的成交率是症状——通常是提示漂移或对手侧攻击。
- **带确定性理由记录所有被拒绝的提案。** 对于合同网管理者，失利投标者需要理解原因。

## 练习

1. 运行 `code/main.py`。确认OG-Narrator在成交率上击败天真LLM。多少？
2. 实现**基于角色的收益改善**（arXiv:2402.05863）——买方仅在叙述中采用"绝望想本周买入"的角色，要约生成器不变。成交率或收益改变吗？
3. 实现思维链**隐藏**：维护不传给对手的私人便签字符串。如果你意外泄露它（通过交换通道模拟）会发生什么？
4. 将合同网扩展为带保留价的N个投标者拍卖。当投标都超过保留价时，管理者如何在最低价和最高质量之间决定？你选择哪种授予规则，为什么？
5. 阅读Bhattacharya等人2025年哈佛谈判项目指标。实现两种不同风格的讨价还价者（激进 vs 公平）。测量对称和不对称配对下的收益方差。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| 合同网 | "任务市场" | Smith 1980年，FIPA 1996年。cfp + propose + accept/reject。权威任务市场。 |
| ZOPA | "可能协议区域" | 买方最高价与卖方最低价的重叠。在其外的要约无法达成。 |
| BATNA | "协商协议的最佳替代方案" | 如果此交易失败的退路。设置你的保留价。 |
| OG-Narrator | "要约生成器 + 叙述者" | 分解：确定性要约，LLM叙述。 |
| Zeuthen策略 | "风险最小化让步" | 经典要约生成器，基于风险限制让步。 |
| Rubinstein讨价还价 | "交替要约均衡" | 带贴现的无限视界讨价还价的博弈论模型。 |
| CoT隐藏 | "隐藏你的推理" | arXiv:2503.06416中获胜者保持私人便签；公开通道仅显示要约。 |
| 角色操纵 | "情绪姿态" | arXiv:2402.05863：来自绝望/紧迫角色的约20%收益增益。 |

# LLM的群体优化（PSO、ACO）

> 仿生优化正在LLM回归。**LMPSO**（arXiv:2504.09247）使用PSO，其中每个粒子的速度是一个提示，LLM生成下一个候选解；在结构化序列输出（数学表达式、程序）上效果良好。**Model Swarms**（arXiv:2410.11163）将每个LLM专家视为模型权重流形上的PSO粒子，报告在9个数据集上跨12个基线**平均提升13.3%**，仅需200个实例。**SwarmPrompt**（ICAART 2025）混合PSO + 灰狼用于提示优化。**AMRO-S**（arXiv:2603.12933）是ACO启发的信息素专家用于多智能体LLM路由——**4.7倍加速**，可解释路由证据，质量门控异步更新将推理与学习解耦。本课在提示参数空间上实现PSO，在智能体路由上实现ACO，测量为什么这些经典算法适合LLM时代，以及何时不适合。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 09 (Parallel Swarm Networks), Phase 16 · 14 (Consensus and BFT)
**Time:** ~75 minutes

## 问题

你有一个提示在你的任务评估上得分62%。你想改进它。天真做法是无梯度手动调整，扩展性差。强化学习需要奖励信号和足够的展开来训练。通过提示的反向传播不可能——提示是离散字符串，不是可微分参数。

经典仿生优化——PSO用于连续搜索空间，ACO用于路径选择——正是为此制度设计的：无梯度、基于种群、每次评估廉价。将它们与LLM配对用于无梯度搜索步，你得到一个令人惊讶的实用优化器。

相同的模式适用于多智能体系统中的智能体*路由*。ACO风格的信息素踪迹记录哪个智能体在哪种任务类型上工作最好，让路由器利用踪迹，并衰减信息素使路线可被重新发现。

## 概念

### PSO复习（Kennedy & Eberhart 1995）

粒子群优化：连续搜索空间中的粒子群。每个粒子有位置`x_i`和速度`v_i`。每次迭代：

```
v_i <- w * v_i + c1 * r1 * (p_best_i - x_i) + c2 * r2 * (g_best - x_i)
x_i <- x_i + v_i
评估fitness(x_i)
如果改进则更新p_best_i
如果全局最佳则更新g_best
```

其中`p_best`是粒子自身最佳，`g_best`是群体最佳，`w, c1, c2`是惯性+认知+社会权重，`r1, r2`是随机因子。

### 在LLM输出上的PSO——LMPSO

arXiv:2504.09247将PSO适配于LLM生成的结构化输出（数学表达式、程序）。每个粒子是候选输出。速度是描述如何将当前输出向个人/全局最佳修改的*提示*。LLM从速度提示生成新输出。速度的"惯性"是如"做小的增量改动"的提示。

这在以下情况良好：
- 输出是结构化的（可解析、可评估）。
- 适应度是自动的（测试运行、算术评估）。
- 种群小（~10-30粒子）使总LLM调用保持可管理。

在适应度需要人工审查时不良好——每次迭代成本变得禁止性。

### Model Swarms

arXiv:2410.11163将PSO从输出层带入*模型*层。每个"粒子"是专家LLM（参数）。群体通过无梯度更新将参数移向集体最佳。报告：在9个数据集上跨12个基线平均提升13.3%，每次迭代仅200个实例。

关键洞见是LLM专家模型已经在共享参数流形（适配器权重、LoRA增量）中相近。在此低维子空间上的PSO廉价且有效。

### ACO复习（Dorigo 1992）

蚁群优化：蚂蚁遍历图；每条路径有信息素踪迹。蚂蚁移动概率按信息素强度加权。完成任务的蚂蚁根据解决方案质量沉积信息素。信息素随时间衰减。

### AMRO-S——用于智能体路由的ACO

arXiv:2603.12933将ACO用于多智能体路由。每种任务类型是"目的地"；每个智能体是可能路线。信息素强化产生良好输出的路线。关键贡献：

- **可解释路由证据。** 信息素强度是人类可读信号。
- **质量门控异步更新。** 信息素仅在质量检查通过后更新，将推理与学习解耦。
- 在多智能体路由基准上**4.7倍加速**。

质量门控重要：没有它，快但错的智能体累积信息素，系统锁死在坏路线上。

### 何时为LLM使用PSO/ACO

**使用PSO当：**
- 搜索空间连续或映射到连续参数（提示嵌入、LoRA权重、数字生成参数）。
- 适应度廉价且自动。
- 种群可小（10-30）。

**使用ACO当：**
- 你有路由或路径选择问题。
- 决策随时间加强（相同任务类型返回）。
- 你需要路由决策的可解释证据。

**两者都不用当：**
- 适应度需要人工审查（每次迭代太昂贵）。
- PSO不涵盖的离散组合搜索空间（改用遗传算法）。
- 实时决策需要严格延迟（PSO/ACO相对于单次启发式收敛慢）。

### 为什么仿生仍然获胜

基于梯度的方法需要可微分信号。LLM输出和路由决策不是平凡可微分的。伪梯度方法（强化学习路由器、DPO风格提示调优器）有效但需要昂贵训练。

PSO和ACO仅需要*评估器*函数。如果你能对候选输出或路由决策评分，你可以在空间上优化。这使得适用性门槛低得多。

### 实际限制

- **种群预算。** N个粒子 × T次迭代 × 每次评估成本。对于LLM评估在约$0.02/次调用，20粒子PSO运行50次迭代花费约$20。相应规划。
- **探索 vs 利用。** 信息素衰减率和PSO惯性权衡；太快衰减→忘记解决方案；太慢→困在早期局部最优。
- **灾难漂移。** 如果适应度景观变化（新数据分布），两者都可收敛然后发散。监控最佳适应度稳定性。

## 构建它

`code/main.py` 实现：

- `LMPSO`——在数值提示参数（temperature、top_k权重）上的PSO。每个粒子的"LLM生成"模拟为脚本化适应度函数。运行算法30次迭代并显示g_best收敛。
- `AMRO_S`——ACO风格路由。3个智能体，4种任务类型，信息素矩阵，100个路由任务。打印（任务类型→智能体选择）分布随时间显示踪迹形成。
- 比较：在相同任务流上的随机路由 vs ACO路由。测量质量和延迟。

运行：

```
python3 code/main.py
```

预期输出：
- LMPSO：g_best适应度在30次迭代中从随机改善到接近最优。
- AMRO-S：信息素表稳定在每种任务类型的正确智能体上；ACO路由在质量上约30-40%击败随机，也减少延迟（更少重试）。

## 交付物

- **从小开始。** 10-20粒子，20-50次迭代。仅当收敛曲线显示明确增益时向上扩展。
- **每轮记录信息素或g_best。** 没有踪迹调试群体优化器是痛苦的。
- **质量门控更新。** 特别是ACO路由：快而错的智能体不得累积信息素。
- **分布变化时重置衰减。** 当你的评估分布变化时，老信息素陈旧；临时重置或加倍衰减率。
- **限制每次迭代成本。** 发出每次迭代成本指标。花费$500/次迭代且增益0.5%的PSO不可交付。

## 练习

1. 运行 `code/main.py`。观察LMPSO收敛。改变种群大小5、10、20、50。在什么大小处收敛时间饱和？
2. 实现"灾难漂移"实验：在第30次迭代后，改变适应度函数。PSO多快适应？重置`p_best`有帮助吗？
3. 在AMRO-S中添加质量门控：仅在评估分数>0.7的运行上沉积信息素。与无门控版本相比，这如何改变收敛？
4. 阅读LMPSO（arXiv:2504.09247）。将论文的"速度即提示"映射回你的数值速度。模拟中丢失了什么，保留了什么？
5. 阅读AMRO-S（arXiv:2603.12933）。实现带异步信息素更新的解耦"推理快速路径"。在持续负载下这如何改变系统延迟？

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| PSO | "粒子群优化" | Kennedy-Eberhart 1995年。基于种群的无梯度优化器。 |
| ACO | "蚁群优化" | Dorigo 1992年。通过信息素踪迹的路径/路线优化。 |
| LMPSO | "带LLM生成的PSO" | arXiv:2504.09247。速度是提示；LLM产生候选解。 |
| Model Swarms | "专家权重上的PSO" | arXiv:2410.11163。模型参数子空间上的无梯度更新。 |
| AMRO-S | "用于智能体路由的ACO" | arXiv:2603.12933。任务类型×智能体的信息素矩阵。 |
| p_best / g_best | "个人/全局最佳" | 迄今发现的每个粒子和群体范围最佳解决方案。 |
| 信息素 | "路由内存" | 边上的强度；随时间衰减；在质量上沉积。 |
| 质量门控更新 | "仅从好运行中学习" | 以质量检查为条件的信息素沉积。 |
| 灾难漂移 | "分布变化" | 适应度景观变化；旧p_best和信息素变为陈旧。 |

# 心智理论与涌现协调

> Li等人（arXiv:2310.10701）显示在合作文本博弈中的LLM智能体表现出**涌��高阶心智理论**（ToM）——关于另一个智能体对第三个智能体信念的推理——但由于上下文管理和幻觉在长期规划上失败。Riedl（arXiv:2510.05174）跨群体测量高阶协同，发现**仅**ToM提示条件产生身份关联分化和目标导向互补性；较低能力LLM仅显示虚假涌现。也就是说，协调涌现是提示条件和模型依赖的，不是免费的。本课实现极简ToM感知智能体，在有和无ToM提示的情况下运行合作任务，并根据Riedl 2025年协议测量协调增量。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 07 (Society of Mind and Debate), Phase 16 · 17 (Generative Agents)
**Time:** ~75 minutes

## 问题

多智能体协调常常看起来神奇：智能体分工、互相预期、避免冗余。通常这种"涌现"是提示工程的产物——有人告诉智能体"协调。"移除提示，移除协调。

Riedl 2025年的发现更严格：在受控条件下，协调仅在智能体被提示推理**其他智能体的思维**（ToM）时涌现。没有ToM提示，即使是强模型也显示不能通过统计控制的协调模式。这对生产很重要：团队交付的"多智能体协调"功能是提示依赖且脆弱的。

本课将ToM视为特定能力（关于信念的信念的推理），构建极简ToM感知智能体，并测量真实协调与提示装饰的区别。

## 概念

### ToM含义

发展心理学：3岁儿童认为任何人的内在世界与他们的匹配。5岁儿童理解他人有不同信念。7岁儿童推理关于信念的信念（"她认为我认为球在杯子下"）。这些是零阶、一阶和二阶ToM。

对于LLM智能体，ToM阶数映射到：

- **零阶：** 无他人模型。智能体仅基于自己的观察行动。
- **一阶：** 智能体有每个其他智能体信念的模型。"Alice相信X。"
- **二阶：** 智能体建模递归信念。"Alice相信Bob相信X。"

Li等人2023年发现一阶和二阶ToM在合作博弈的LLM智能体中涌现，但随长视界和不可靠通信而退化。

### Sally-Anne测试，简言之

1985年错误信念测试：Sally把弹珠放在篮子A中，离开。Anne把它移到篮子B。Sally回来时会在哪里找？有一阶ToM的儿童说篮子A（Sally的信念与现实不同）。没有的儿童说篮子B。

GPT-4时代的LLM当直白提出时通过Sally-Anne风格测试。当叙事长、场景改变几次或问题间接措辞时它们失败。这是生产LLM中ToM的2026年实际状态。

### Riedl的协调测量

Riedl（arXiv:2510.05174）构建了群体规模测试：N个智能体，合作目标，可变提示条件。测量：

1. **身份关联分化。** 智能体是否随时间发展稳定角色区别？
2. **目标导向互补性。** 智能体的行动是否互补（不同子任务）而非重复？
3. **高阶协同。** 群体是否达到任何子集不能达到的统计测量。

结果：仅在ToM提示条件下，所有三个指标产生高于基线的信号。没有ToM提示，中等能力模型的指标徘徊在随机附近。大型模型在没有显式ToM提示时显示一些协调，但效果比显式提示小。

### 协调幻觉

没有统计控制，演示中的"涌现协调"经常反映：

- 烘焙在协调中的提示工程（说"一起工作"的系统提示）。
- 观察者偏差（我们看到我们期望的模式）。
- 事后选择成功运行。

营销"涌现协调"而没有可测量信号的生产系统应被视为营销。测量再声称。

### 极简ToM感知智能体

结构：

```
智能体状态：
  自己的信念：    {智能体相信的事实}
  他人模型：   {其他智能体id -> {智能体归因于他们的信念}}
  最近N次行动： [他人行动的历史]

观察更新：
  - 从直接观察更新自己的信念
  - 从他们的行动 + 先前信念更新他人模型[智能体id]

行动选择：
  - 枚举候选行动
  - 对每个行动，预测每个其他智能体给定其建模信念将下一步做什么
  - 选择在这些预测下最大化联合结果的行动
```

`other_models` 属性是ToM状态。一阶ToM仅保留一级。二阶添加 `other_models[i][other_models_of_j]` ——我认为智能体i认为智能体j相信什么。

### 为什么长视界有害

Li等人记录：上下文限制导致智能体忘记哪个信念属于谁。幻觉将错误信念添加到他人智能体模型。两者产生随复利增长的"我认为他以为X"错误。

论文中及2024-2026年后续记录的缓解措施：

- **提示中的显式ToM状态。** 结构化格式：`{agent_id: belief_list}`。强制检索保持身份-信念绑定。
- **更短的推理链。** 每回合更少的ToM更新减少复利幻觉。
- **外部ToM存储。** 在LLM上下文外维护模型；每回合仅注入相关部分。

### ToM在生产中在哪里失败

- **对抗设置。** 好ToM的智能体更容易被操纵（你可以建模它们对你的建模，然后利用）。
- **异构团队。** 当模型不同时，对一个对手有效的ToM模型不泛化。
- **真地依赖任务。** ToM关乎信念；如果正确性依赖事实，ToM可能是分散注意力。

### 你实际可以测量的协调

团队协调真实而非提示装饰的三个实际信号：

1. **随时间的互补性。** 在多轮任务中，智能体的行动是否覆盖不相交的子任务？
2. **预期。** 智能体A在T+1回合的行动是否依赖于对B在T+2回合的行动的预测，且该预测证明正确？
3. **纠正。** 当A在T回合误读B的信念时，A是否在T+2回合前纠正？

这些在有日志的多智能体系统中是可测量的。它们是"协调"叙事的实质性版本。

## 构建它

`code/main.py` 实现：

- `ToMAgent`——追踪自己的信念和每个其他智能体的信念模型。
- 合作任务：三个智能体必须从三个盒子中收集三个令牌；每个盒子能放一个令牌。智能体不能通信；它们从彼此的行动中推断意图。
- 两种配置：`zeroth_order`（无ToM）和`first_order`（带一级信念模型的ToM）。
- 跨200次随机试验的测量：完成率、重复率（两个智能体瞄准同一盒子）、完成平均回合数。

运行：

```
python3 code/main.py
```

预期输出：零阶智能体约35%重复并约60%在10回合内完成试验。一阶ToM智能体约5%重复并约95%完成。增量是可测量的协调效应。

## 交付物

协调声称检查清单：

- **控制条件。** 你的系统的一个不带协调提示的版本。测量两者。
- **统计测试。** 系统和控制的差异在你的指标上在 `p < 0.05` 是否显著？
- **互补性测量。** 随时间的行动分离度，不仅是最终成功。
- **失败案例日志。** 当智能体协调错误时，ToM状态是什么样子？
- **模型能力披露。** 如果效果在较小模型上消失，就说出��。

## 练习

1. 运行 `code/main.py`。确认一阶ToM将重复率降低约7倍。当你扩展到5个智能体和5个盒子时差距持续吗？
2. 实现二阶ToM（智能体A建模B对C的想法）。相对于一阶改进了吗？在什么任务上？
3. 向ToM状态注入**幻觉**：每回合随机翻转一个信念。这对一阶性能的降低有多大？
4. 阅读Li等人（arXiv:2310.10701）。复现"长视界退化"发现：当回合从10增长到30时，你一阶ToM性能如何变化？
5. 阅读Riedl 2025年（arXiv:2510.05174）。在你的模拟日志上实现高阶协同统计量。效果在没有ToM提示条件时存在吗？

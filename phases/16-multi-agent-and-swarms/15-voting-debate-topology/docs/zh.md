# 投票、自我一致性与辩论拓扑

> 最廉价的聚合：采样N个独立智能体，多数投票。Wang等人2022年自我一致性用同一模型采样N次完成。多智能体通过**异构**智能体扩展以摆脱单一文化——不同模型、不同提示、不同温度、不同上下文。超越多数投票，辩论拓扑重要：MultiAgentBench（arXiv:2503.01935，ACL 2025）评估了星形/链式/树形/图协调，发现**图在研究上最佳**，超过约4个智能体后出现"协调税"。AgentVerse（ICLR 2024）记录了两种涌现模式——志愿者行为和从众行为——从众既是特性（寻找共识）也是风险（群体思维，第24课）。本课映射拓扑空间，构建每种变体，并测量协调税。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 07 (Society of Mind and Debate), Phase 16 · 14 (Consensus and BFT)
**Time:** ~75 minutes

## 问题

辩论可以提高准确率（Du等人，arXiv:2305.14325）。也可以降低它。辩论是否有帮助取决于四个结构选择：

1. 谁对谁说话（拓扑）。
2. 多少轮（Du 2023：轮次和智能体数独立重要）。
3. 智能体是否异构（不同基础模型打破单一文化）。
4. 是否存在对抗性声音（严格论证 vs. 稻草人论证）。

将"运行5个智能体并投票"加到任务上的团队经常相对于单智能体退步。失败不是随机的。它们追踪拓扑和异构性。本课是拓扑地图。

## 概念

### 自我一致性，单模型基线

Wang等人2022年（"Self-Consistency Improves Chain of Thought Reasoning"）在temperature > 0下对同一模型采样N次并对推理路径答案多数投票。GSM8K结果：N=40采样相对于单次贪婪解码有显著增益。自我一致性是多智能体投票的单智能体前身。

限制：自我一致性使用一个基础模型。错误由构造相关。如果模型有系统性偏差，所有N采样共享它。

### 多智能体投票，异构扩展

用N个*不同*智能体替代N次采样。不同基础模型（Claude、GPT、Llama），不同提示，不同工具访问。收益：不相关错误。成本：不同智能体花费不同金额；协调它们增加开销。

2026年异构辩论的规范名称为**A-HMAD**——对抗异构多智能体辩论。未被普遍采用，但论文使用该术语指"不同模型辩论，减少来自单一文化崩塌的相关错误。"

### 四种拓扑

```
star                chain               tree                graph

    ┌─A─┐           A─B─C─D         ┌──A──┐              A───B
    │   │                           │     │              │ × │
    B   C                           B     C              D───C
    │   │                          / \   / \
    D   E                         D   E F   G           （完全连接）
```

星形：一个中心，所有其他仅与中心交谈。等价于无反向通道的监督者-工作者。
链式：线性，每个智能体看到前一个的输出。类似流水线。
树形：层次化，被层次化智能体系统使用（第06课）。
图：任意到任意。包括完全连接团和任意DAG。

### 协调税（MultiAgentBench）

MultiAgentBench（MARBLE，ACL 2025，arXiv:2503.01935）在包括研究、编程和规划的任务套件上基准测试了星形、链式、树形、图。关键测量结果：

- **图**拓扑在研究任务上获胜。信息任意到任意流动；智能体可以互相批评。
- **星形**在快速答案事实任务上获胜。中心过滤并整合。
- **链式**在逐步流水线（阶段提纯）上获胜。
- **协调税**在图拓扑约4个智能体后出现。墙钟和token成本增长快于质量。

4智能体上限是经验性的，非根本性的。它反映2026年LLM上下文容量：每个智能体的上下文被同伴输出填满，一旦每个人能看到每个人，添加第N+1个智能体的边际价值下降。

### 多智能体辩论策略（"Should we be going MAD?"）

arXiv:2311.17371是2023年MAD策略调查。被其他人复现的关键发现：与自我一致性*结构相似*的MAD变体（独立采样 + 聚合）在使用相同预算时经常性能不如自我一致性。当智能体真正异构且辩论具有对抗结构（一个智能体反对）时，MAD帮助最大。

### AgentVerse涌现模式

AgentVerse（ICLR 2024）记录了两种从多智能体辩论中涌现的行为，即使没有显式设计：

- **志愿者。** 智能体主动提供帮助（"我可以做下一步"）。有用：它为子任务将工作分配给最有能力的智能体。
- **从众。** 智能体调整立场以匹配批评者，即使批评者是错的。这是谄媚（第14课）的辩论等价物。

从众是为什么辩论到一致奖励欺凌者。有界轮次加独立评委缓解。

### 异构性：实际移动准确率的旋钮

实践文献中2024-2026年的模式：将你的N个智能体之一换成不同基础模型比增加N多1给更大的准确率提升。直觉是单一文化——每个新独立错误来源比额外相关采样更有价值。

在极限上，异构性胜过数量。在大多数有干净真地答案的任务上，三个不同模型胜过五个单一模型副本。

### 陪审团方法

Sibyl框架（在Minsky-LLM文献中引用）形式化了"陪审团"——一小组专门化智能体，通过在每个阶段投票来提炼答案。与普通多数投票不同，陪审团有角色：一人交叉质询，一人提供上下文，一人对合理性评分。陪审团方法是普通投票（廉价，单一文化倾向）和全MAD（昂贵，从众倾向）之间的中点。

### 何时带辩论的投票占主导

- 问题有真地答案（事实、数学、代码行为）。投票收敛有意义。
- 智能体可以访问不同来源或工具（异构性可用）。
- 轮次有界（典型2-3）且有独立法官或验证者。
- 预算允许3-5个智能体。在图拓扑上超过5-7个，协调税占主导。

### 何时带辩论的投票有害

- 问题是意见形状的。智能体收敛到看起来最自信的答案，而非最正确的。
- 所有智能体共享基础模型。单一文化使共识无意义。
- 轮次无界。从众每次都赢。
- 任务简单。带N=5自我一致性的单智能体更便宜且同样准确。

## 构建它

`code/main.py` 实现：

- `run_star(agents, hub, question)`——中心轮询每个工作者，聚合。
- `run_chain(agents, question)`——顺序提纯。
- `run_tree(root, children, question)`——带深度为2聚合的层次化。
- `run_graph(agents, question, rounds)`——全对全辩论，有界轮次。
- 脚本化异构度旋钮：每个智能体有 `error_bias` 指示其系统性错误。
- 测量工具在N=3、5、7时运行每种拓扑，报告（准确率、总token、模拟墙钟）。

运行：

```
python3 code/main.py
```

预期输出：拓扑 × N → （准确率、token、延迟）的表格。图在N=3-5时在研究风格任务上获胜；星形在快速事实任务上获胜；图在N=7时显示协调税（延迟膨胀快于准确率）。

## 交付物

对任何集成：

- 从一个强基础模型使用N=5的**自我一致性**开始。它是廉价基线。
- 如果准确率重要，升级到N=3的**异构投票**。测量增量。
- 仅当任务有结��（研究、多步）且有界轮次可行时，升级到**辩论拓扑**。
- 始终记录少数派簇。当少数派持续正确时，你有多样性信号。
- 与准确率一起基准测试墙钟和token。"以10倍成本获得更好准确率"是商业决策。

## 练习

1. 运行 `code/main.py`。绘制图拓扑的协调税曲线：准确率vs N，token vs N。在哪个N处曲线转折？
2. 实现A-HMAD：三个具有刻意不同偏差的智能体。全相同偏差基线与A-HMAD在第14课单一文化攻击上的对比如何？
3. 在图拓扑中添加一个不投票、仅对最终共识评分的"法官"角色。这改变涌现的从众行为吗？
4. 阅读AgentVerse论文（ICLR 2024）。识别你的实现最强烈表现出哪种涌现行为。你能通过提示变化引出相反行为吗？
5. 阅读MultiAgentBench（arXiv:2503.01935）第4节（拓扑实验）。使用你的工具在论文的一个任务上复现"图-获胜-研究"结果。

# 心智社会与多智能体辩论

> Minsky在1986年的前提——智能是一个专家社会——被每个十年重新发现。2023年Du等人将其转化为具体算法：多个LLM实例提出答案，互相阅读答案，批评并更新。经过N轮后，它们在六个推理和事实性任务上收敛到超过零样本CoT和自我反思的共识。两个发现很重要：**多个智能体**和**多轮**独立贡献。社会超过单智能体独白；多轮交换超过一次性投票。

**Type:** Learn + Build
**Languages:** Python (stdlib)
**Prerequisites:** Phase 16 · 04 (Primitive Model)
**Time:** ~60 minutes

## 问题

自我一致性——从单一模型采样多次并取多数答案——是你可以附加的最廉价的推理改进。它有效，但饱和得很快。你可以将采样加倍，却看不到另一个有意义的跳跃。

辩论打破了饱和。不是从单一模型的N个独立采样，而是N个智能体阅读彼此的推理并进行修订。采样之间的相关性下降（它们不再是i.i.d.），而收敛点通常正确，而i.i.d.投票时自信地错误。

## 概念

### Du等人2023年算法

来自arXiv:2305.14325（ICML 2024）：

1. N个智能体分别对问题产生一个初始答案。
2. 对于轮 r = 2..R：每个智能体被展示其他智能体在第r-1轮的答案，并被要求"考虑到这些，给出你更新的答案。"
3. 经过R轮后，对最终答案进行多数投票。

论文在MMLU、GSM8K、传记、MATH和事实性基准上测试。辩论一致击败CoT和自我反思。

### 两个独立旋钮

同一论文的消融实验：

- **仅智能体数量**（1轮，N的多数投票）在大多数任务上击败单智能体，但趋于平合。
- **仅轮数**（1个智能体看到自己先前的推理）帮助很少——反思的已知弱点。
- **两者结合**产生大的跳跃。多个智能体之间的多轮交换驱动了增益。

### 为什么有效

两个机制：

1. **暴露于分歧。** 当一个智能体看到另一个智能体的推理链得出不同结论时，它必须要么辩护要么更新。不论哪种，第r+1轮的上下文比第r轮更丰富。
2. **相关错误减少。** 在自我一致性中，所有采样来自同一模型，因此错误相关——你平均为一个自信的错误答案。不同模型或不同种子去相关化。不同的*辩论观点*进一步去相关化。

### 异构辩论

A-HMAD和相关后续工作使用*不同的基础模型*用于不同的智能体。Llama + Claude + GPT辩论减少了单一文化崩塌（第26课），因为一个模型族的相关错误不被其他家族共享。

缺点：参与辩论的弱模型可以将共识拖向它的错误答案（见"Should we be going MAD?"，arXiv:2311.17371）。

### NLSOM——129智能体扩展

Zhuge等人（"Mindstorms in Natural Language-Based Societies of Mind," arXiv:2305.17066）将此想法扩展到129个成员的社会。结果：专门化和自我组织随规模涌现，系统在如视觉问答等任务上超越单智能体。

### 失败模式

- **谄媚级联。** 所有智能体遵从听起来最自信的智能体。辩论崩塌到最大声音。提示对抗性角色（"一个智能体必须论证反对立场"）有所帮助。
- **主题漂移。** 多轮辩论从原始问题漂移。缓解：每轮重新注入问题。
- **计算爆炸。** N个智能体 × R轮 = N·R次LLM调用，每个上下文都在增长。5智能体、5轮辩论是在增长上下文下的25次调用。每个问题的成本可能超过单次CoT调用的10倍。

## 构建它

`code/main.py` 在一个数学问题上运行3智能体 × 3轮辩论，每个智能体以不同的（可能错误的）答案开始。智能体是脚本化的——每个通过以脚本化置信度加权邻居答案的平均值来"更新"。在逐轮日志中可以看到收敛。

演示展示两个关键效果：

- 单轮交换将智能体移近正确答案。
- 超出第2轮的额外轮次显示递减收益（匹配Du等人的平合）。

运行：

```
python3 code/main.py
```

## 运用

`outputs/skill-debate-configurator.md` 为新任务配置辩论：智能体数量、轮数、异构性（相同模型 vs 混合）、角色分配（对称 vs 一个对抗）。它还在运行前估计token成本。

## 交付物

如果你交付辩论：

- **限制轮数为3。** Du等人 显示3轮捕获大部分收益。更多是成本，而非质量。
- **限制智能体数量为5。** 超过5，上下文膨胀和成本占主导。
- **默认异构。** 池中至少两个不同的基础模型。
- **对抗性席位。** 一个智能体被提示无论如何都要反对。打破谄媚。
- **记录每一轮。** 隐藏中间轮的辩论系统不能调试或审计。

## 练习

1. 运行 `code/main.py`，然后将轮数设为5观察递减收益。额外收敛在哪一轮停止？
2. 添加第四个具有对抗性角色的智能体：总是与当前多数意见不同。这破坏还是改善收敛？
3. 绘制（打印）每轮的一致分数（在多数答案上的智能体比例）。何时达到1.0，那等同于"正确"吗？
4. 阅读Du等人第4节消融实验。使用此代码复现"仅智能体" vs "仅轮次" vs "两者"的结果。
5. 阅读"Should we be going MAD?"（arXiv:2311.17371）并列出两种超出轮询的辩论变体——例如法官主导、辩论链、对抗。

## 关键术语

| 术语 | 人们常说的 | 实际含义 |
|------|----------------|------------------------|
| 心智社会 | "Minsky的想法" | 智能是互动专家；1986年框架现在通过LLM辩论操作化。 |
| 多智能体辩论 | "智能体争论" | N个智能体提出、互相批评、在R轮中修订、多数投票。 |
| 共识 | "它们同意了" | 不是认识论真相——只是多数答案上的比例。可能自信地错误。 |
| 轮次 | "交换步骤" | 一轮 = 每个智能体阅读其他智能体并更新一次。 |
| 异构辩论 | "混合模型家族" | 使用不同基础模型去相关化错误。 |
| 谄媚级联 | "每个人都同意声音大的" | 辩论失败，智能体遵从最自信的智能体，不论正确性如何。 |
| NLSOM | "129智能体社会" | 自然语言心智社会；Zhuge等人的扩展版本。 |
| 相关错误 | "相同模型，相同Bug" | 为什么自我一致性饱和；跨不同观点的辩论去相关化。 |

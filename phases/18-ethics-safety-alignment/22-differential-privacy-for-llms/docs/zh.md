# LLM 的差分隐私

> DP-SGD 仍是标准 — 噪声注入梯度更新提供形式的（epsilon、delta）保证。计算、内存和效用开销可观；参数高效的 DP 微调（LoRA + DP-SGD）是常见 2025 配置（ACM 2025）。两组证据存在张力：基于金丝雀的成员推理（Duan et al., 2024）报告对语言模型的有限成功；训练数据提取（Carlini et al., 2021; Nasr et al., 2025）恢复了大量逐字记忆。解决（arXiv:2503.06808, 2025 年 3 月）：差距在于测量的内容 — 插入金丝雀 vs"最可提取"数据。新金丝雀设计可在无影子模型下进行基于损失的 MIA，并在以现实 DP 保证训练于真实数据的 LLM 上产生第一个非平凡的 DP 审计。替代方案：PMixED（arXiv:2403.15638）— 推理时通过专家混合对下一 token 分布的私有预测；DP 合成数据生（Google Research 2024）。新兴攻击：通过 LLM 反馈的差分隐私反转 — 置信分数泄漏。

## 问题

LLM 会记忆。Carlini et al. 2021 证明生产语言模型可按需复现逐字训练文本。DP 是形式化的防御：训练使输出可证明地对任何单个训练样本不敏感。2024-2025 证据表明 DP-SGD 是必要的，但部署的 ε 值可能与威胁模型不匹配。

## 概念

### (ε, δ)-差分隐私

一个随机算法 M 是 (ε, δ)-DP 的，如果对于任何相差一例的两个数据集和任何事件 S：
P(M(D) in S) <= e^ε * P(M(D') in S) + δ。

解释：输出分布足够接近（由 ε 参数化），以致任何单一个体的贡献不能被可靠推断，除概率 δ 外。

### DP-SGD

Abadi et al. 2016。标准配方：
1. 采样一个小批次。
2. 计算每一样本梯度。
3. 将每一样本梯度剪裁到阈值 C。
4. 将剪裁后的梯度和，添加标准差 σ * C 的高斯噪声。
5. 使用噪声和更新参数。

隐私成本由记账员（矩记账员、Rényi DP 记账员）跟踪。LLM 文献中报告的 ε 值因威胁模型、数据敏感度和效用目标而异；没有普遍"安全"的默认 ε。已发表的示例大致在 ε ≈ 1–10 的某些 LLM 训练设置中，但这些都是说明性的 — 不是推荐默认值。较低的 ε 通常需要更多噪声并可能增加效用损失。

### LoRA + DP-SGD

对前沿模型的完整 DP-SGD 是禁止的。LoRA (Hu et al. 2022) 将梯度更新限制到小型适配器，减少了每一样本梯度存储。LoRA + DP-SGD 是常见的 2025 年配置。DP 保证适用于适配器；基础模型保持固定。

### 2024-2025 张力

两条证据线：

- **金丝雀 MIA（Duan et al. 2024）。** 将唯一金丝雀插入训练数据，测量成员推理攻击者能否识别它们。报告对语言模型的有限成功。表明 MIA 困难。
- **训练数据提取（Carlini 2021, Nasr et al. 2025）。** 用前缀提示模型；测量它是否恢复训练中的逐字文本。报告了大量记忆。表明 MIA 在相关意义上是容易的。

解决：差异在于所测量内容。金丝雀 MIA 测量插入样本；提取测量自然被记忆的样本。后者更接近真实威胁模型。

### PMixED

推理时私有预测替代方案。不训练私有模型，在推理时对下一 token 分布应用 DP 机制。对分布进行专家混合加噪声。避免 DP 训练的效用损失。

### 差异隐私反转攻击

通过 LLM 反馈新兴攻击：攻击者查询模型并观察置信分数；由于 DP 噪声具有已知分布，重复查询可能恢复被噪声隐藏的信号。置信分数泄漏是 DP 审计的新维度。

## 练习

1. 运行 `code/main.py`。追踪 10k、50k、100k 步训练后的 ε。ε 如何随步数增长？为什么？

2. 比较带 LoRA 的 DP-SGD 与 PMixED：一者需要 DP 训练，另一者在推理时添加噪声。在设计威胁模型下哪种方法提供更好的保证？

3. 金丝雀 MIA 与训练数据提取：为什么最可提取样本比插入金丝雀更容易？这对 DP 保证在 LLM 中的解释意味着什么？

4. 置信分数泄漏 DP 反转：多次查询模型。设计一个限制置信分数泄漏同时保持隐私的协议。

5. 对于 DP-SGD，ε=8 常见。在 ε=8 下，一个样本以 e^8 ≈ 2980 因子包含的概率变化。这"安全"吗？依赖于什么威胁模型？

## 核心术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| (ε, δ)-DP | "差分私有" | 输出分布与单个样本的有界差异 |
| DP-SGD | "噪声梯度更新" | 剪裁梯度 + 高斯噪声用于 GPU 上的隐私 |
| 金丝雀 MIA | "插入样本测试" | 将唯一金丝雀插入训练以测量是否可检测 |
| 训练数据提取 | "逐字恢复" | 暴露模型以恢复记忆文本 |
| PMixED | "推理时隐私" | 推理时对分布加噪声的专家混合 |
| ε 记账员 | "隐私预算跟踪器" | 跟踪训练期间消耗的 ε |

# 指令遵循作为对齐信号

> 后续对 RLHF 的每一个批评都是针对这个管线。在你研究优化压力如何扭曲代理之前，你必须先看到代理。InstructGPT (Ouyang et al., 2022) 定义了参考架构：在指令-响应对上进行监督微调，在成对偏好排名上训练奖励模型，以及针对奖励模型的 PPO 加对 SFT 策略的 KL 惩罚。1.3B InstructGPT 比 175B GPT-3 更受偏好。这单一结果是每个前沿实验室在 2026 年仍然交付 RLHF 形状的后训练管线的理由。

**Type:** Learn
**Languages:** Python (stdlib, toy three-stage pipeline)
**Prerequisites:** Phase 10 · 06 (SFT), Phase 10 · 07 (RLHF), Phase 10 · 08 (DPO)
**Time:** ~45 minutes

## 学习目标

- 说出 InstructGPT 管线的三个阶段以及每个阶段使用的损失。
- 解释为什么 1.3B 指令调优模型在人类偏好评估中击败了原始 175B GPT-3。
- 陈述第 3 阶段的 KL 惩罚在保护什么，以及为什么移除它会使行为崩溃为模式寻求。
- 描述对齐税以及 Ouyang et al. 用来对抗它的 PPO-ptx 缓解措施。

## 问题

预训练语言模型补全文本。它们不回答问题。问 GPT-3 "写一个反转列表的 Python 函数"，你经常得到另一个提示，因为大部分训练分布是网页文本，继续跟着更多网页文本。模型在做它的工作 — 但工作是错的。

每个重要的实验室用来修复这个问题的代理是人类偏好。两个补全交给评分者；评分者选择更好的那个；奖励模型学习评分者。然后 RL 循环将策略转向奖励模型评高分的输出。这就是完整的 InstructGPT 论文观点，用三句话说。论文的其余部分是工程。

## 概念

### 阶段 1：监督微调 (SFT)

收集提示-响应对，其中响应是一个善意的真人会写的内容。Ouyang et al. 使用了来自标注者和 OpenAI API 的 13k 提示。用标准交叉熵损失在该数据上微调基础模型。

SFT 给你什么：模型现在回答问题而不是延续问题。它不给你什么：任何关于当多个合理答案时评分者偏好哪个的信号。

### 阶段 2：奖励模型 (RM)

对于每个提示，从 SFT 模型中采样 K 个补全。标注者对它们排名。训练一个奖励模型，对任何提示-响应对评分，使得对于 `y_w` 被偏好于 `y_l` 的对：

```
L_RM = -log sigmoid(r(x, y_w) - r(x, y_l))
```

这是 Bradley-Terry 成对偏好损失。RM 通常从 SFT 模型初始化，LM 头替换为标量头。

奖励模型很小：6B 对 175B InstructGPT 已足够。它们也很脆弱 — 论文第 5 节主要是关于在小规模时出现的奖励攻击行为。

### 阶段 3：带 KL 惩罚的 PPO

定义目标：

```
J(pi) = E_{x~D, y~pi(.|x)} [ r(x, y) ] - beta * KL(pi(.|x) || pi_SFT(.|x))
```

用 PPO 最大化。KL 项保持 `pi` 不会从 SFT 策略漂移太远。没有它，优化器会找到对抗性样本 — 在 RM 下评分很高的字符串，因为是 RM 从未见过的，而不是因为人类真的偏好它们。

KL 系数 `beta` 是唯一最重要的 RLHF 超参数。太低：奖励攻击。太高：相对 SFT 没有改进。

### 对齐税

RLHF 后，模型被人类偏好但在标准基准（SQuAD、HellaSwag、DROP）上退化。Ouyang et al. 称此为对齐税并用 PPO-ptx 修复：将预训练梯度混入 RL 目标，使模型不会忘记它从未被奖励过的下游任务。

```
J_ptx(pi) = J(pi) + gamma * E_{x~D_pretrain} [ log pi(x) ]
```

PPO-ptx 成为标准。Anthropic、DeepMind 和 Meta 都使用某种变体。

### 结果

1.3B InstructGPT (SFT + RM + PPO-ptx) 在约 70% 的时间里被标注者偏好于 175B 的基础 GPT-3。差距在生产流量的隐藏测试提示上更大。从这个数字读出两件事：

1. 对齐是不同于能力的轴。175B 模型有更多能力；1.3B 模型有更多对齐；标注者偏好对齐的那个。
2. 能力下限由基础模型设定。你不能通过 RLHF 让基础模型知道它从未见过的知识。

### 为什么这是 Phase 18 的参考点

后续课程中的每个批评 — 奖励攻击（第 2 课）、DPO（第 3 课）、奉承（第 4 课）、CAI（第 5 课）、休眠代理（第 7 课）、对齐伪装（第 9 课）— 都是反对这个管线的某个部分。奖励攻击攻击阶段 2。DPO 将阶段 2 和 3 折叠在一起。CAI 替换了人类标注者。奉承表明标注者是有偏差的信号。对齐伪装表明策略可以完全绕过阶段 3。不在脑中首先建立这管线，你无法理解这些批评中的任何一个。

## 使用它

`code/main.py` 在玩具偏好数据上模拟三个阶段。基础"策略"是动作 {A, B, C} 上的有偏差硬币。阶段 1 SFT 在 200 个提示上模仿标注者动作。阶段 2 从 500 个成对排名拟合 Bradley-Terry 奖励模型。阶段 3 运行简化的 PPO 更新，带对 SFT 策略的 KL 惩罚。你可以观察奖励攀升、KL 散度增长和策略漂移 — 你也可以关闭 KL 项看到奖励攻击在 50 个更新步骤内出现。

要观察的内容：

- `beta = 0.1` vs `beta = 0.0` 下的奖励轨迹。
- 训练步骤上的 KL(pi || pi_SFT)。
- 与标注者偏好相比的最终动作分布。

## 交付它

本课产出 `outputs/skill-instructgpt-explainer.md`。给定 RLHF 管线描述或论文摘要，它识别三个阶段中哪个被修改、每个阶段使用了什么损失，以及是否存在 KL 惩罚或等效正则化。

## 练习

1. 运行 `code/main.py`。设置 `beta = 0.0` 并报告 200 步 PPO 后的动作分布。用一段话解释模式寻求行为。

2. 修改奖励模型使其对动作 B 有 +0.5 的偏差（模拟奖励错误）。运行 `beta = 0.1` 的 PPO。KL 惩罚是否阻止策略利用偏差？在什么 `beta` 下利用变得可见？

3. 阅读 Ouyang et al. (arXiv:2203.02155) 图 1。通过运行 PPO 1、5、20、100 步并测量相对于 SFT 模型的偏好来复现标注者偏好曲线。

4. 论文第 4.3 节报告 1.3B InstructGPT 在约 70% 的时间里击败 175B GPT-3。为什么这个比率在隐藏生产提示上比标注者自己的提示上更高？

5. 在相同偏好数据上用 DPO（Phase 10 · 08）替换 PPO 损失。比较最终策略漂移（到 SFT 的 KL）和最终奖励。在匹配奖励下哪种方法漂移更远？

## 核心术语

| 术语 | 人们怎么说 | 实际含义 |
|------|-----------|---------|
| SFT | "指令调优" | 阶段 1：在提示-响应对上进行交叉熵微调 |
| 奖励模型 | "RM" | 在（提示、响应）上的标量回归器，用 Bradley-Terry 在成对标签上训练 |
| Bradley-Terry | "成对偏好损失" | -log sigmoid(r_w - r_l)；将成对排名简化为二分类 |
| KL 惩罚 | "正则化器" | `beta * KL(pi \|\| pi_SFT)` — 保持 RL 策略靠近 SFT 锚点 |
| PPO-ptx | "带预训练混合的 PPO" | 向 PPO 目标添加一部分预训练对数似然以抵消对齐税 |
| 对齐税 | "RLHF 退化" | RLHF 后在 RLHF 未瞄准的标准基准上的下降 |
| 标注者偏好 | "真实值" | 人类排名样本；RM 是此的统计代理，而非"人类价值观" |

# 生成模型 — 分类与历史

> 每个图像模型、文本模型、视频模型和 3D 模型都属于五个桶之一。选错桶，你将与数学斗争数周。选对桶，该领域过去十二年的进展会清晰地堆叠在你脑海中。

**类型：** 学习
**语言：** Python
**前置条件：** 第二阶段（机器学习基础），第三阶段（深度学习核心），第七阶段 · 14（Transformer）
**时间：** 约 45 分钟

## 问题

生成模型只做一件事：给定从某个未知分布 `p_data(x)` 中抽取的训练样本，输出看起来像是从同一分布中产生的新样本。人脸、句子、MIDI 文件、蛋白质结构——如果眯起眼睛看，都是同一个问题。

困难在于 `p_data` 存在于具有数百万维度的空间中（512x512 RGB 图像约 786k 维），样本位于该空间内的一个薄流形上，而你只有大约 1 千万个示例。暴力估计密度是无望的。每个生成模型都是一个妥协，将一个难题换成一个稍微不那么难的问题。

五个家族在过去十二年中幸存下来。知道每个家族做出的妥协，就能告诉你为什么它在某些任务上胜出而在其他任务上崩溃。

## 概念

![生成模型的五个家族 — 按它们建模的内容分类](../assets/taxonomy.svg)

**1. 显式密度，可处理。** 将 `log p(x)` 写为你实际可以求值的总和。自回归模型（PixelCNN、WaveNet、GPT）因式分解 `p(x) = ∏ p(x_i | x_<i)`。归一化流（RealNVP、Glow）将 `p(x)` 构建为简单基础分布的可逆变换。优点：精确似然，干净的训练损失。缺点：自回归推理是串行的（长序列时慢），流需要可逆架构（架构限制）。

**2. 显式密度，近似。** 从下方界定 `log p(x)`（ELBO）并优化该界。VAE（Kingma 2013）使用具有变分后验的编码器-解码器。扩散模型（DDPM，Ho 2020）训练一个隐式优化加权 ELBO 的去噪器。扩散是 2026 年主导的图像、视频和 3D 骨干。

**3. 隐式密度。** 完全跳过密度；学习一个产生样本的生成器 `G(z)` 和一个区分真假的判别器 `D(x)`。GAN（Goodfellow 2014）。推理速度快（一次前向传播），但训练出了名地不稳定。即使在 2026 年，StyleGAN 1/2/3 对于固定领域的照片写实（人脸、卧室）仍然是 SOTA。

**4. 基于分数 / 连续时间。** 直接学习对数密度的梯度 `∇_x log p(x)`（分数）。Song 和 Ermon（2019）表明分数匹配将扩散推广到 SDE。流匹配（Lipman 2023）是 2024-2026 年的热门：无模拟训练，更直的路径，比 DDPM 快 4-10 倍的采样。Stable Diffusion 3、Flux、AudioCraft 2 都使用流匹配。

**5. 离散编码上的基于 Token 的自回归。** 用 VQ-VAE 或残差量化器将高维数据压缩为短序列的离散 token，然后使用 Transformer 建模 token 序列。Parti、MuseNet、AudioLM、VALL-E、Sora 的补丁分词器都使用这种方法。这是桶 1 加一个学到的分词器。

## 五个问题分类法

当一篇新的生成模型论文出现时，在阅读方法部分之前回答这五个问题。

1. **正在建模什么？** 像素、潜在向量、离散 token、3D 高斯、网格、波形？
2. **密度是显式的还是隐式的？** 他们写了 `log p(x)` 吗？
3. **采样：一次性还是迭代？** 迭代意味着更慢的推理；一次性通常意味着对抗性或蒸馏的。
4. **条件化：无条件、类别、文本、图像、姿态？** 这决定了损失和架构脚手架。
5. **评估：FID、CLIP 分数、IS、人类偏好、任务准确率？** 每个都有已知的失败模式（参见第 14 课）。

你将为这个阶段的每一课重新回答这五个问题。到最后，它们将成为条件反射。

## 动手构建

本课的代码是一个轻量级可视化：使用三种玩具方法（核密度、离散直方图和一个"类 GAN"最近邻生成器）从样本中拟合 1-D 高斯混合，这样你就可以在可以在一个屏幕上打印的问题上看到显式与隐式密度之间的区别。

运行 `code/main.py`。它从双模式高斯混合中抽取 2000 个样本，然后打印：

```
显式密度（直方图）：p(x in [-0.5, 0.5]) ≈ 0.38
近似密度（KDE）：    p(x in [-0.5, 0.5]) ≈ 0.41
隐式（最近样本生成器）： 打印 20 个新样本，无 p(x)
```

注意：前两个让你问"这个点的可能性有多大？"第三个不能。这是*显式 vs 隐式*的区别，对未来的每一课都很重要。

## 使用它

在 2026 年，何种家族用于何种任务？

| 任务 | 最佳家族 | 为什么 |
|------|-------------|-----|
| 照片写实人脸，狭窄领域 | StyleGAN 2/3 | 仍然最锐利、推理最快。 |
| 通用文本到图像 | 潜在扩散 + 流匹配 | SD3、Flux.1、DALL-E 3。 |
| 快速文本到图像 | 整流流 + 蒸馏 | SDXL-Turbo、SD3-Turbo、LCM。 |
| 文本到视频 | Diffusion Transformer + 流匹配 | Sora、Veo 2、Kling。 |
| 语音 + 音乐 | 基于 Token 的自回归（AudioLM、VALL-E、MusicGen）或流匹配（AudioCraft 2） | 离散 token 扩展成本低。 |
| 3D 场景 | 高斯溅射拟合，扩散先验 | 3D-GS 用于重建，扩散用于新视角。 |
| 密度估计（无采样） | 流 | 唯一具有精确 `log p(x)` 的家族。 |
| 模拟 / 物理 | 流匹配，分数 SDE | 直线路径，平滑向量场。 |

## 关键术语

| 术语 | 人们怎么说 | 它实际上的含义 |
|------|-----------------|-----------------------|
| 生成模型 | "它创造新东西" | 学习 `p_data(x)` 的采样器，可选地暴露 `log p(x)`。 |
| 显式密度 | "你可以求值它" | 模型提供闭式或可处理的 `log p(x)`。 |
| 隐式密度 | "GAN 风格" | 只有采样器——无法对给定点求值 `p(x)`。 |
| ELBO | "证据下界" | `log p(x)` 的可处理下界；VAE 和扩散优化它。 |
| 分数 | "对数密度的梯度" | `∇_x log p(x)`；扩散和 SDE 模型学习这个场。 |
| 流形假设 | "数据生活在表面上" | 高维数据集中在低维流形上；降维有效的原理。 |
| 自回归 | "预测下一个片段" | 将联合分布因式分解为条件分布的乘积。 |
| 潜在向量 | "压缩编码" | 低维表示，解码器可以从中重建输入。 |

## 生产笔记：五个家族，五种推理形状

每个家族映射到不同的推理服务器成本曲线。推理文献将 LLM 推理框架化为预填充 + 解码；相同的分解也适用于此：

- **自回归（桶 1 和 5）。** 串行解码主导延迟；KV 缓存、连续批处理和推测解码都直接适用。
- **VAE / 扩散 / 流匹配（桶 2 和 4）。** 没有 LLM 意义上的解码。成本 = `num_steps × step_cost`，而 `step_cost` 是在完整潜在分辨率上的 transformer 或 U-Net 前向传播。生产旋钮是步数（DDIM / DPM-Solver / 蒸馏）、批量大小和精度（bf16 / fp8 / int4）。
- **GAN（桶 3）。** 一次前向传播。没有调度，没有 KV 缓存。TTFT ≈ 总延迟。这就是 StyleGAN 在狭窄领域 UX 上仍然胜出的原因。

当你在论文摘要中看到"比扩散更快"时，将其翻译为"更少步数 × 相同步成本"或"相同步数 × 更便宜的步成本"。其他一切都是营销。

# 朴素贝叶斯

> "朴素"的假设是错误的，但无论如何它都有效。这就是它的美。

**类型：** 构建
**语言：** Python
**先决条件：** 阶段 2，第 01-07 课（分类、贝叶斯定理）
**时间：** ~75 分钟

## 学习目标

- 使用拉普拉斯平滑从头实现多项式朴素贝叶斯用于文本分类
- 解释为什么朴素独立性假设在数学上是错误的但在实践中产生正确的类排名
- 比较多类式、伯努利和高斯朴素贝叶斯变体，并为给定特征类型选择正确的一种
- 在高维稀疏数据上评估朴素贝叶斯与逻辑回归，并解释偏差-方差权衡的作用

## 问题

你需要分类文本。邮件分为垃圾邮件或非垃圾邮件。客户评价分为正向或负向。支持工单分类。你有数千个特征（每个词一个）和有限的训练数据。

大多数分类器在这里会失败。逻辑回归需要足够的样本来可靠估计数千个权重。决策树每次在一个词上分割并严重过拟合。KNN 在 10,000 维中毫无意义，因为每个点与每个其他点同样远。

朴素贝叶斯处理这个问题。它做了一个数学上错误的假设（给定类别，每个特征独立于每个其他特征），但它仍然在文本分类上优于"更聪明"的模型，特别是在小型训练集上。它通过单次数据遍历训练。它扩展到数百万特征。它产生概率估计（尽管由于独立性假设通常校准不良）。

## 概念

### 贝叶斯定理（快速复习）

```
P(类别 | 特征) = P(特征 | 类别) * P(类别) / P(特征)
```

类别的最高 `P(类别 | 特征)` 获胜。

### 朴素独立性假设

确切计算 `P(特征 | 类别)` 需要估计所有特征一起的联合概率。在 10,000 个单词的词汇表中，你将需要估计超过 2^10,000 种可能组合的分布。不可能。

朴素假设：给定类别，每个特征是有条件独立的。

```
P(w1, w2, ..., wn | 类别) = P(w1 | 类别) * P(w2 | 类别) * ... * P(wn | 类别)
```

这个假设明显是错误的。词"机器"和"学习"在任何文档中都不是独立的。但分类器不需要正确的概率估计。它需要正确的排名。

### 为什么它仍然有效

1. **排名胜过校准。** 我们不需要正确的概率。只需要正确的胜者。
2. **高偏差，低方差。** 独立性假设是一个强先验，防止过拟合（偏差-方差权衡实际行动）。
3. **特征冗余抵消。** 相关特征提供冗余证据。分类器对正确类别双重计算它。

### 三种变体

**多项式朴素贝叶斯**：将每个特征建模为计数。最适合词频或 TF-IDF 值的文本数据。

```
P(词_i | 类别) = (词_i 在类别中的计数 + alpha) / (类别中的总词数 + alpha * 词汇量大小)
```

**高斯朴素贝叶斯**：将每个特征建模为正态分布。最适合连续特征。

```
P(x_i | 类别) = (1 / sqrt(2 * pi * var)) * exp(-(x_i - mean)^2 / (2 * var))
```

**伯努利朴素贝叶斯**：将每个特征建模为二值的（存在或不存在）。最适合短文本或二值特征向量。

### 拉普拉斯平滑

当一个词出现在测试数据中但从未出现在训练数据中某个特定类别时：
`P(词 | 类别) = 0/N = 0`。一个零乘以整个乘积使 `P(类别 | 特征) = 0`，无论所有其他证据如何。

拉普拉斯平滑向每个特征计数添加一个小计数 `alpha`（通常为 1）。

| Alpha | 效果 | 何时使用 |
|-------|--------|-------------|
| 0.001 | 几乎无平滑 | 非常大的训练集 |
| 0.1 | 轻微平滑 | 大型训练集 |
| 1.0 | 标准拉普拉斯平滑 | 默认起点 |
| 10.0 | 强平滑 | 非常小的训练集 |

### 对数空间计算

乘以数百个概率（每个小于 1）导致浮点下溢。解决方案：在对数空间中工作。

```
log P(类别 | x1, x2, ..., xn) = log P(类别) + sum_i log P(xi | 类别)
```

这使预测变成一个矩阵乘法：
```
log_scores = X @ log_feature_probs.T + log_class_priors
```

### 朴素贝叶斯 vs 逻辑回归

| 方面 | 朴素贝叶斯 | 逻辑回归 |
|--------|------------|-------------------|
| 类型 | 生成式（模型 P(X\|Y)） | 判别式（模型 P(Y\|X)） |
| 训练 | 计数频率 | 优化损失函数 |
| 小数据 | 更好（强先验帮助） | 更差（不足以估计权重） |
| 大数据 | 更差（错误假设的损害） | 更好（灵活边界） |
| 特征 | 假设独立性 | 处理相关性 |
| 速度 | 单次遍历，非常快 | 迭代优化 |

## 构建它

```python
class MultinomialNB:
    def __init__(self, alpha=1.0):
        self.alpha = alpha

    def fit(self, X, y):
        classes = np.unique(y)
        n_classes = len(classes)
        n_features = X.shape[1]
        self.classes_ = classes
        self.class_log_prior_ = np.zeros(n_classes)
        self.feature_log_prob_ = np.zeros((n_classes, n_features))
        for i, c in enumerate(classes):
            X_c = X[y == c]
            self.class_log_prior_[i] = np.log(X_c.shape[0] / X.shape[0])
            counts = X_c.sum(axis=0) + self.alpha
            self.feature_log_prob_[i] = np.log(counts / counts.sum())
        return self
```

拟合后，预测只是矩阵乘法。这就是为什么朴素贝叶斯如此快速。

## 使用它

```python
from sklearn.naive_bayes import GaussianNB, MultinomialNB
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.pipeline import Pipeline

text_clf = Pipeline([
    ("tfidf", TfidfVectorizer()),
    ("classifier", MultinomialNB(alpha=0.1)),
])
text_clf.fit(train_texts, train_labels)
```

## 关键术语

| 术语 | 实际含义 |
|------|----------------------|
| 朴素贝叶斯 | 应用贝叶斯定理及特征条件独立假设的分类器 |
| 条件独立性 | P(A, B \| C) = P(A \| C) * P(B \| C) |
| 拉普拉斯平滑 | 向每个特征添加小计数以防止零概率 |
| 生成式 vs 判别式 | 模型 P(X\|Y) vs 模型 P(Y\|X) |
| 对数空间 | 加对数而不是乘概率以防止浮点下溢 |

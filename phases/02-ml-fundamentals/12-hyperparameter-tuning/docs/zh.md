# 超参数调优

> 超参数是你在训练开始前调整的旋钮。调整好是一个平庸模型和一个伟大模型之间的区别。

**类型：** 构建
**语言：** Python
**先决条件：** 阶段 2，第 11 课（集成方法）
**时间：** ~90 分钟

## 学习目标

- 从头实现网格搜索、随机搜索和贝叶斯优化，并比较它们的样本效率
- 解释为什么当大多数超参数的有效维度较低时，随机搜索优于网格搜索
- 使用替代模型和采集函数构建贝叶斯优化循环来引导搜索
- 设计一个通过适当交叉验证避免过拟合验证集的超参数调优策略

## 问题

你的梯度提升模型有学习率、树的数量、最大深度、每叶最小样本数、子采样比和列采样比。那是六个超参数。如果每个有 5 个合理值，网格有 5^6 = 15,625 个组合。训练每个需要 10 秒。尝试所有需要 43 小时的计算。

网格搜索是明显的方法，也是规模上最差的方法。随机搜索用更少的计算做得更好。贝叶斯优化通过从过去的评估中学习做得更好。知道使用哪种策略，以及哪些超参数真正重要，可以节省数天浪费的 GPU 时间。

## 概念

### 参数 vs 超参数

参数在训练期间学习（权重、偏置、分割阈值）。超参数在训练开始前设置，控制学习如何发生。

| 超参数 | 控制什么 | 典型范围 |
|---------------|-----------------|---------------|
| 学习率 | 每次更新的步长 | 0.001 到 1.0 |
| 树/epoch 数量 | 训练多长时间 | 10 到 10,000 |
| 最大深度 | 模型复杂度 | 1 到 30 |
| 正则化 (lambda) | 过拟合预防 | 0.0001 到 100 |
| 批量大小 | 梯度估计噪声 | 16 到 512 |
| Dropout 率 | 丢弃的神经元比例 | 0.0 到 0.5 |

### 网格搜索

网格搜索评估指定值的每种组合。它是穷举的且易于理解，但随超参数数量呈指数级缩放。

网格搜索有一个根本缺陷：如果一个超参数重要而另一个不重要，大多数评估被浪费。

### 随机搜索

随机搜索从分布而不是网格中采样超参数。在相同的评估预算下，你对每个超参数获得更多唯一值。

为什么随机优于网格（Bergstra & Bengio, 2012）：
- 大多数超参数的有效维度较低。6 个超参数中通常只有 1-2 个对给定问题重要。
- 网格搜索在不重要的维度上浪费评估。
- 随机搜索在相同预算下更密集地覆盖重要维度。
- 在 60 次随机试验中，你有 95% 的机会找到最优值 5% 范围内的点。

### 贝叶斯优化

随机搜索忽略结果。贝叶斯优化使用过去的评估来决定下一步搜索哪里。

两个关键组件：
**替代模型**：一个评估成本低廉的模型（通常是高斯过程），近似昂贵的目标函数。
**采集函数**：通过平衡利用（在已知好的点附近搜索）和探索（在不确定性高的地方搜索）决定下一步评估哪里。

贝叶斯优化通常用比随机搜索少 2-5 倍的评估找到更好的超参数。

### 早停

策略：
- **基于耐心**：如果验证损失在连续 N 个 epoch 内没有改善则停止
- **中位数剪枝**：如果试验的中间结果比同一步完成试验的中位数差则停止
- **Hyperband**：分配小预算给许多配置，然后逐步增加最佳配置的预算

### 超参数重要性

并非所有超参数同等重要。
**高重要性**：学习率、估计器/epoch 数、正则化强度
**中重要性**：最大深度/层数、最小每叶样本数/权重衰减
**低重要性**：最大特征数、特定激活函数选择、批量大小（在合理范围内）

## 关键术语

| 术语 | 实际含义 |
|------|----------------------|
| 超参数 | 训练前设置的控制学习过程的参数 |
| 网格搜索 | 对每个超参数组合的穷举搜索 |
| 随机搜索 | 从分布中随机采样超参数 |
| 贝叶斯优化 | 使用过去评估的替代模型引导搜索 |
| 采集函数 | 平衡利用和探索来决定下一步评估哪里 |
| 早停 | 在不好的配置完成完整训练预算前停止它们 |
| Hyperband | 自适应资源分配策略，逐渐增加最佳配置的预算 |

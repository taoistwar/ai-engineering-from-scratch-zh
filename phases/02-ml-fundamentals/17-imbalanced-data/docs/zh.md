## 问题

你构建了一个欺诈检测模型。它获得 99.9% 的准确率。你庆祝。然后你意识到它对每笔交易都预测"非欺诈"。

这不是 bug。当只有 0.1% 的交易是欺诈时，这是理性的选择。模型学到总是猜测多数类可以最小化整体误差。这技术上是正确的，但完全无用。

这在每个真实分类问题上都会发生。疾病诊断：1% 阳性率。网络入侵：0.01% 攻击。制造缺陷：0.5% 有缺陷。垃圾邮件过滤：20% 垃圾邮件。流失预测：5% 流失者。少数类越重要，它们往往越罕见。

准确率失败是因为它平等对待所有正确预测。我们需要强制模型关注稀有但重要类别的指标、技术和训练策略。

## 概念

### 为什么准确率失败

考虑一个有 1000 个样本的数据集：990 个负类，10 个正类。一个总是预测负类的模型：
准确率 = (0 + 990) / 1000 = 99.0%。模型捕获零欺诈，零疾病，零缺陷。但准确率说 99%。

### 更好的指标

- **精确率** = TP / (TP + FP)。标记为正向的东西中有多少实际是正向的？
- **召回率** = TP / (TP + FN)。实际正向中有多少被捕获了？
- **F1 分数** = 2 * P * R / (P + R)。调和平均。
- **F-beta 分数** = (1+beta^2)*P*R / (beta^2*P+R)。当 beta > 1 时，召回率更重要。
- **AUPRC**（精确率-召回率曲线下面积）。比 AUC-ROC 对不平衡数据更具信息性。
- **Matthews 相关系数**（MCC）仅在两个类上都表现好时给出高分。

### SMOTE：合成少数过采样技术

SMOTE 创建新的合成少数类样本，这些样本合理但不是副本：
1. 对每个少数类样本 x，在其他少数类样本中找到其 k 个最近邻
2. 随机选择一个邻居
3. 在 x 和该邻居之间的线段上创建新样本

公式：`新样本 = x + random(0, 1) * (邻居 - x)`

### 采样策略比较

| 策略 | 改变的数据 | 风险 | 何时使用 |
|----------|-------------|------|-------------|
| 过采样 | 少数类重复 | 过拟合 | 小数据集，中等不平衡 |
| 欠采样 | 多数类移除 | 信息损失 | 大数据集，想要快速训练 |
| SMOTE | 合成少数类添加 | 边界噪声 | 中等不平衡，有足够少数类样本用于 k-NN |

### 类别权重

不是改变数据，而是改变模型对待错误的方式。为少数类误分类分配更高权重。

对于 950 个负类和 50 个正类的二分类问题：
- 负类权重 = 1000 / (2 * 950) = 0.526
- 正类权重 = 1000 / (2 * 50) = 10.0

正类得到 19 倍的权重。模型被迫关注少数类。

在逻辑回归中，这修改损失函数：
```
加权损失 = -sum(w_i * [y_i * log(p_i) + (1-y_i) * log(1-p_i)])
```

## 关键术语

| 术语 | 实际含义 |
|------|----------------------|
| 不平衡数据 | 一个类比其他类多得多的数据集 |
| SMOTE | 通过插值创建合成少数类样本 |
| 精确率 | 被标记为正向的正确比例 |
| 召回率 | 实际正向中被捕获的比例 |
| F-beta | 带有可调召回率权重的 F1 泛化 |
| MCC | 同时惩罚两个类别上性能差的平衡指标 |
| 类别权重 | 为更稀有的类别的错误分配更高惩罚 |

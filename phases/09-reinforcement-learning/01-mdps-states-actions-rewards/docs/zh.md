# MDP、状态、动作与奖励

> 马尔可夫决策过程是五件事：状态、动作、转移、奖励、折扣。强化学习中一切——Q-learning、PPO、DPO、GRPO——都在这个形状上优化。学会它一次，其余强化学习的内容免费阅读。

**类型：** 学习
**语言：** Python
**前置条件：** 第一阶段 · 06（概率与分布），第二阶段 · 01（机器学习分类）
**时间：** 约 45 分钟

## 问题

你在编写象棋机器人。或库存规划器。或交易代理。或训练推理模型的 PPO 循环。四个不同的领域，一个令人惊讶的事实：所有四个都塌缩为相同的数学对象。

监督学习给你 `(x, y)` 对并要求你拟合一个函数。强化学习给你没有标签——只有一个状态流、你采取的动作和一个标量奖励。这一步走子是否赢得对局？补货决策是否节省了钱？交易是否盈利？LLM 刚刚产生的 token 是否导致评判者给出更高的奖励？

你无法从这个流中学习，直到你形式化它。"我看到了什么"，"我做了什么"，"接下来发生了什么"，"那有多好"——每个都必须成为一个你可以推理的对象。那个形式化就是马尔可夫决策过程。本阶段中的每个 RL 算法，包括最后的 RLHF 和 GRPO 循环，都在这个形状上优化。

## 概念

![马尔可夫决策过程：状态、动作、转移、奖励、折扣](../assets/mdp.svg)

**五个对象。**

- **状态** `S`。代理需要决定的一切。在 GridWorld 中，是单元格。在象棋中，是棋盘。在 LLM 中，是上下文窗口加任何记忆。
- **动作** `A`。选择。上/下/左/右移动。走一步棋。发出一个 token。
- **转移** `P(s' | s, a)`。给定状态 `s` 和动作 `a`，下一状态的分布。在象棋中是确定性的，在库存中是随机的，在 LLM 解码中几乎是确定性的。
- **奖励** `R(s, a, s')`。标量信号。赢 = +1，输 = -1。收入减去成本。GRPO 中的对数似然比项。
- **折扣** `γ ∈ [0, 1)`。未来奖励相对于当下的权重有多少。`γ = 0.99` 买入约 100 步的视野；`γ = 0.9` 买入约 10 步。

**马尔可夫性质** `P(s_{t+1} | s_t, a_t) = P(s_{t+1} | s_0, a_0, …, s_t, a_t)`。未来仅依赖当前状态。如果不依赖，则状态表示不完整——不是方法失败，是状态失败。

**策略与回报。** 策略 `π(a | s)` 将状态映射到动作分布。回报 `G_t = r_t + γ r_{t+1} + γ² r_{t+2} + …` 是未来奖励的折扣和。价值 `V^π(s) = E[G_t | s_t = s]` 是在策略 `π` 下从 `s` 开始的预期回报。Q 值 `Q^π(s, a) = E[G_t | s_t = s, a_t = a]` 是以特定动作开始的预期回报。每个 RL 算法都估计这两者之一，然后相应地改进 `π`。

**Bellman 方程。** 本阶段一切内容使用的是不动点方程：

`V^π(s) = Σ_a π(a|s) Σ_{s', r} P(s', r | s, a) [r + γ V^π(s')]`
`Q^π(s, a) = Σ_{s', r} P(s', r | s, a) [r + γ Σ_{a'} π(a'|s') Q^π(s', a')]`

这些将预期回报分解为"本步的奖励"加上"你着陆处的折扣价值"。递推的。第 9 阶段的每个算法要么迭代此方程到收敛（动态规划），从中采样（蒙特卡洛），要么一步自举（时间差分）。

## 动手构建

### 步骤 1：一个微型确定性 MDP

一个 4×4 GridWorld。代理从左上角开始，终点在右下角，每步奖励为 -1，动作为 `{up, down, left, right}`。参见 `code/main.py`。

```python
GRID = 4
TERMINAL = (3, 3)
ACTIONS = {"up": (-1, 0), "down": (1, 0), "left": (0, -1), "right": (0, 1)}

def step(state, action):
    if state == TERMINAL:
        return state, 0.0, True
    dr, dc = ACTIONS[action]
    r, c = state
    nr = min(max(r + dr, 0), GRID - 1)
    nc = min(max(c + dc, 0), GRID - 1)
    return (nr, nc), -1.0, (nr, nc) == TERMINAL
```

五行。这就是整个环境。确定性转移，恒定步惩罚，吸收终端状态。

### 步骤 2：展开一个策略

策略是从状态到动作分布的函数。最简单的：均匀随机。

```python
def uniform_policy(state):
    return {a: 0.25 for a in ACTIONS}

def rollout(policy, max_steps=200):
    s, total, steps = (0, 0), 0.0, 0
    for _ in range(max_steps):
        a = sample(policy(s))
        s, r, done = step(s, a)
        total += r
        steps += 1
        if done:
            break
    return total, steps
```

运行随机策略 1000 次。这个 4×4 棋盘的平均回报约为 -60 到 -80。最优回报是 -6（直线右下路径）。弥合那个差距就是第 9 阶段的一切。

### 步骤 3：通过 Bellman 方程精确计算 `V^π`

对于小型 MDP，Bellman 方程是一个线性系统。枚举状态，应用期望，迭代直到值停止变化。

```python
def policy_evaluation(policy, gamma=0.99, tol=1e-6):
    V = {s: 0.0 for s in all_states()}
    while True:
        delta = 0.0
        for s in all_states():
            if s == TERMINAL:
                continue
            v = 0.0
            for a, pi_a in policy(s).items():
                s_next, r, _ = step(s, a)
                v += pi_a * (r + gamma * V[s_next])
            delta = max(delta, abs(v - V[s]))
            V[s] = v
        if delta < tol:
            return V
```

这是迭代策略评估。它是 Sutton 和 Barto 中的第一个算法，是后续每个 RL 方法的理论基础。

### 步骤 4：`γ` 是一个具有物理意义的超参数

有效视野大致为 `1 / (1 - γ)`。`γ = 0.9` → 10 步。`γ = 0.99` → 100 步。`γ = 0.999` → 1000 步。

太低，代理近视行事。太高，信用分配变得嘈杂，因为许多早期步骤对远期奖励分担责任。LLM RLHF 通常使用 `γ = 1`，因为回合短且有界。控制任务使用 `0.95–0.99`。长期策略游戏使用 `0.999`。

## 缺陷陷阱

- **非马尔可夫状态。** 如果你需要最近三个观测来决定，"状态"不仅仅是当前观测。修复：堆叠帧（Atari 上的 DQN 堆叠 4 帧）或使用递归状态（观测上的 LSTM/GRU）。
- **稀疏奖励。** 只有胜利奖励使在大状态空间中学习几乎不可能。塑造奖励（中间信号）或用模仿引导（第 9 阶段 · 09）。
- **奖励黑客。** 优化代理奖励经常产生病态行为。OpenAI 的赛船代理永远原地旋转收集能量提升而不完成比赛。始终从目标结果定义奖励，而非代理。
- **折扣误设。** 在无限视野任务上 `γ = 1` 使每个价值为无限。始终用有限视野或 `γ < 1` 进行限制。
- **奖励尺度。** {+100, -100} vs {+1, -1} 的奖励给出相同的最优策略但梯度幅度截然不同。在插入 PPO/DQN 前归一化到 `[-1, 1]` 附近。

## 使用它

2026 年技术栈在触及代码之前将每个 RL 流水线归约为 MDP：

| 情况 | 状态 | 动作 | 奖励 | γ |
|-----------|-------|--------|--------|---|
| 控制（运动、操作） | 关节角度 + 速度 | 连续力矩 | 任务特定塑造 | 0.99 |
| 游戏（象棋、围棋、扑克） | 棋盘 + 历史 | 合法走法 | 赢=+1 / 输=-1 | 1.0（有限） |
| 库存 / 定价 | 库存 + 需求 | 订货量 | 收入 - 成本 | 0.95 |
| LLM 的 RLHF | 上下文 token | 下一个 token | 结束时的奖励模型分数 | 1.0（回合约 200 token） |
| 推理的 GRPO | 提示 + 部分响应 | 下一个 token | 结束时的验证器 0/1 | 1.0 |

在编写任何训练循环之前写下五个元组。大多数"RL 不工作"的错误报告都追溯到一个在纸面上就已破坏的 MDP 公式化。

## 练习

1. **简单。** 在 `code/main.py` 中实现 4×4 GridWorld 和随机策略展开。运行 10,000 个回合。报告回报的均值和标准差。与最优回报（-6）比较。
2. **中等。** 对均匀随机策略以 `γ ∈ {0.5, 0.9, 0.99}` 运行 `policy_evaluation`。对每个 `γ` 以 4×4 网格打印 `V`。解释为什么终端附近的状态值随更大的 `γ` 增长更快。
3. **困难。** 将 GridWorld 变成随机的：每个动作以概率 `p = 0.1` 滑到相邻方向。重新评估均匀策略。`V[start]` 是变好还是变差？为什么？

## 关键术语

| 术语 | 人们怎么说 | 它实际上的含义 |
|------|-----------------|-----------------------|
| MDP | "强化学习设置" | 满足马尔可夫性质的元组 `(S, A, P, R, γ)`。 |
| 状态 | "代理看到的东西" | 所选策略类下未来动态的充分统计量。 |
| 策略 | "代理的行为" | 条件分布 `π(a | s)` 或确定性映射 `s → a`。 |
| 回报 | "总奖励" | 从当前步开始的折扣和 `Σ γ^t r_t`。 |
| 价值 | "状态有多好" | 在 `π` 下从 `s` 开始的预期回报。 |
| Q 值 | "动作有多好" | 在 `π` 下从 `s` 以第一个动作 `a` 开始的预期回报。 |
| Bellman 方程 | "动态规划递推" | 价值/Q 分解为一步奖励加折扣后继价值的不动点。 |
| 折扣 `γ` | "未来 vs 现在" | 远期奖励的几何权重；有效视野 `~1/(1-γ)`。 |
